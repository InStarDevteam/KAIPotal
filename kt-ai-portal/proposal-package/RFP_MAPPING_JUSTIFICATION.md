# RFP 매핑 근거 설명

> 본 문서는 각 화면/기능이 RFP 기능번호에 왜 대응하는지 설명하는 근거 자료입니다.  
> 제안서에서 "왜 이 화면이 해당 요구사항에 부합하는지" 답변할 때 활용합니다.

## 1. 메인 포털

- **대응 기능번호**: 1~8
- **대응 화면**: `01-portal-dashboard.png`
- **매핑 근거**:
  - 포털 메인 화면은 플랫폼 전체 현황을 요약하여 제공하는 기능(1~4)에 해당합니다.
  - 데이터셋·AI 모델·프로젝트·크레딧·K-RMF·시스템 상태를 한 눈에 보여주는 요약 카드는 현황 파악(5~6)에 해당합니다.
  - 공지사항, Quick Links, 최신 등록 자산은 사용자 편의성 및 메뉴 접근성(7~8)에 해당합니다.

## 2. 로그인/인증

- **대응 기능번호**: 9~12, 45~55
- **대응 화면**: `09-backstage-signin.png`, `09-keycloak-login.png`
- **매핑 근거**:
  - Backstage Sign-In 화면은 OIDC 및 게스트 로그인 선택(9~12)을 제공합니다.
  - Keycloak Login은 OIDC 인증, 비밀번호 정책, 세션 정책, MFA(45~55)의 실제 구현체입니다.

## 3. 사용자 관리

- **대응 기능번호**: 21~35
- **대응 화면**: `07-admin-console-user-management.png`
- **매핑 근거**:
  - 사용자 등록 신청·승인·반려(21~25)
  - 사용자/외부 사용자 목록 및 상세 관리(26~30)
  - 조직/부서 관리(31~35)
