# 국방지능형플랫폼포털 기능별 견적서 초안

> 본 문서는 PoC 이후 실제 운영 구축을 위한 기능별 M/M 산정 초안입니다.  
> 금액은 산정하지 않고 M/M 기준만 제시하며, 실제 견적 시 환경/일정/범위에 따라 보정해야 합니다.

## 1. 산정 전제

| 항목 | 내용 |
|------|------|
| 프로젝트 기간 | 6개월 |
| 기반 기술 | Backstage, Keycloak, OpenSearch, OpenMetadata, Docker Compose/Kubernetes |
| PoC 재활용 | 화면 UI 및 mock 기반 상태 전환 로직을 일부 재사용 |
| 산정 단위 | 화면 개발, Backend/API, 외부 연동, 테스트/검증, 문서화 |
| 제외 항목 | 인프라/클리우드 비용, 상용 SW 라이선스, 사용자 교육, 유지보수 |

## 2. 산정 범위

- 포털 UI 및 Backend/API 구현
- Keycloak/OIDC 연동 및 권한 정책
- OpenSearch 통합검색 및 OpenMetadata 연동
- DB 설계 및 CRUD API
- 외부 시스템 연동 인터페이스 설계/구현
- 단위/통합/보안 테스트 및 산출물 정리

## 3. 제외 범위

- 하드웨어 및 클라우드 인프라 구축 비용
- 상용 소프트웨어 라이선스
- 보안 인증(ISMS-P, CC 등) 획득 비용
- 기존 레거시 시스템 리팩토링
- 사용자 교육 및 매뉴얼 제작(별도 산정)

## 8. 운영 전환 추가 고려사항

- PostgreSQL 등 운영 DB 이관
- HTTPS/TLS 적용 및 보안 인증서 관리
- Secret 관리 체계 도입(Vault 등)
- Kubernetes 배포 및 HPA/VPA
- 로깅/모니터링/알림 체계 구축
- 백업/복구 전략 수립

## 9. 리스크 및 가정사항

- PoC 화면은 mock 데이터 기반이므로 실제 연동 공수는 별도 산정
- 외부 시스템(Keycloak, OpenSearch, OpenMetadata, K8s, OpenStack, CMP) 인터페이스 변경 시 추가 공수 발생 가능
- 보안등급 기반 접근제어 정책 확정 시 UI/API 변경 가능
- RFP 요구사항 변경 시 M/M 재조정 필요

- 데이터 마이그레이션 규모
- 보안 인증 및 컴플라이언스 범위
- 사용자 교육 및 매뉴얼 제작 범위
- 유지보수 기간 및 SLA
