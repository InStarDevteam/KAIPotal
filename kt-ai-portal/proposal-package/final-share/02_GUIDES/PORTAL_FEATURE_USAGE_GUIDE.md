# 포털 기능 사용 설명서

> 일반 사용자 관점에서 각 메뉴의 목적, 사용 대상, 주요 기능, 연계 플랫폼, 후속 연동 범위를 정리합니다.

## 1. 일반 사용자 기준 사용 방법

1. 포털 접속: `https://kai-platform-d0ae0.web.app`
2. 로그인: 접근코드 `ictway` 입력 또는 Google 계정으로 로그인
3. 통합 대시보드에서 전체 현황 확인
4. 통합검색/서비스 카탈로그에서 필요한 데이터/도구 탐색
5. 프로젝트/워크스페이스, 반입·반출, 크레딧 메뉴에서 업무 신청
6. 마이페이지/환경설정에서 개인 설정 및 이력 확인

## 2. 메뉴 설명
