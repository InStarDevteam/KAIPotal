> 본 자료는 국방지능형플랫폼포털의 전체 구조, 사용자 흐름, 메뉴 설명, 플랫폼 간 관계를 이해하기 쉽게 정리한 설명서입니다.

## 2. 포털의 역할

### 2.1 포털이 직접 수행하는 기능

- 통합 인증 및 로그인 선택
- 메뉴/권환/RBAC 관리
- 사용자 등록/승인/외부 사용자 관리
- 프로젝트/반출/크레딧 업무 신청 및 승인 workflow
- 데이터/모델/도구 통합 검색 및 카탈로그 조회
- 요구사항 대응현황, API 연계현황, 업무흐름 시나리오 관리
- K-RMF 증빙 자료 등록 및 감사로그 조회
- 육해공군 멀티테넌트 관리

### 2.2 포털이 연계하는 기능

- 데이터 플랫폼: 데이터셋/모델 메타데이터 조회, 반출 파일 연계
- AI 플랫폼: AI 작업환경/모델 상태 조회, 성과물 반출 연계
- 지능형 클라우드/CMP: 자원/쿼터/사용량 조회, 추가 자원 신청
- 인증/권한: SSO, 사용자/그룹/역할/테넌트 정보 조회
- 보안/K-RMF: 반입·반출 승인 workflow, 증빙 동기화, 감사 로그 수집

### 2.3 포털이 직접 수행하지 않는 기능

- 데이터 직접 저장/가공/분석
- AI 모델 직접 학습/배포
- 물리 인프라/VM/컨테이너 직접 생성
- 보안 통제 직접 수행

## 3. 사용자 유형별 사용 흐름

### 3.1 일반 사용자

1. 포털 접속 → 접근코드 또는 Google 로그인
2. 통합 대시보드에서 전체 현황 확인
3. 통합검색/서비스 카탈로그에서 필요한 데이터/도구 탐색
4. 프로젝트/워크스페이스, 반입·반출, 크레딧 메뉴에서 업무 신청
5. 마이페이지/환경설정에서 개인 설정 및 이력 확인

### 3.2 데이터 엔지니어

- 데이터 플랫폼 작업환경/도구 조회
- 데이터셋 등록/정제 작업 수행
- 메타데이터 및 품질 결과를 포털에 반영
- 프로젝트에서 데이터셋 활용 가능하도록 연계

### 3.3 데이터 사이언티스트

- 통합검색 → 데이터 플랫폼 메타데이터 조회
- 데이터셋 상세/보안등급 확인
- 프로젝트 활용 신청
- AI/데이터 작업환경에서 분석
- 반출 필요 시 승인 workflow

### 3.4 AI 개발자

- 프로젝트 생성
- AI 작업환경/자원 신청
- 클라우드/CMP에서 실행환경 생성
- AI 플랫폼에서 모델 학습/평가
- 포털에서 상태/사용량 조회
- 성과물 반출 신청/승인

### 3.5 프로젝트 관리자

- 프로젝트 현황 조회
- 자원/크레딧 사용량 모니터링
- 추가 자원/쿼터 신청
- 멤버 권한 관리
- 반입·반출 승인/반려

### 3.6 군별 관리자

- 군별 조직/사용자/프로젝트 범위 확인
- 인증/권한 시스템에서 권한 조회
- 쿼터/사용량 조회
- 권한 위임/회수
- 잔여량/장애 현황 확인

### 3.7 보안 관리자

- 반출 신청 접수
- 보안등급/승인권자 확인
- 승인/반려 처리
- 증빙 자료 및 감사 로그 연계
- 정기 K-RMF 평가 자료 활용

### 3.8 관리자 (제안/사업관리자)

- SFR별 구현현황 조회
- 메뉴 대응현황 확인
- 포털-플랫폼 API 후보 검토
- 업무흐름 시나리오 검토
- CSV 추출 → 제안/보고 자료 작성

## 4. 일반 사용자 기준 사용 방법

### 4.1 포털 접속

- URL: `https://kai-platform-d0ae0.web.app`
- 접근코드: `ictway`
- Google 로그인: 관리자용

### 4.2 로그인

- 접근코드 입력 후 `접근코드로 입장`
- 또는 관리자는 `Google 계정으로 로그인` 선택

### 4.3 통합 대시보드 확인

- 등록 데이터셋, AI 모델, 진행 중 프로젝트, 반출 대기 건수
- 크레딧 요약, K-RMF 진행률, 시스템 상태
- 공지사항, Quick Links, 최신 등록 자산

### 4.4 통합검색

- 검색어 입력
- 검색 대상 유형, 보안등급, 소스 시스템, 태그 필터
- 결과 선택 시 상세 메타데이터 조회

### 4.5 서비스/도구 카탈로그 조회

- 분석 프레임워크, 개발도구, 데이터 도구, 시각화 도구, 라벨링 도구 탭
- 도구 상세/버전/제공 방식 확인
- 워크스페이스 적용을 위한 도구 선택/요청

### 4.6 프로젝트/워크스페이스 확인

- 프로젝트 목록/상세
- 멤버/자원/워크스페이스 상태
- 프로젝트 생성 신청

### 4.7 반입·반출 신청/승인 상태 확인

- 신청 목록/상세
- 반입/반출 신청 등록
- 보안등급/승인 상태/이력 확인

### 4.8 크레딧 사용량 확인

- 프로젝트별 크레딧 잔액/사용량
- 충전/사용 이력
- 부족 알림 확인

### 4.9 마이페이지/환경설정 확인

- 프로필/비밀번호/세션
- 내 프로젝트/자원/크레딧 이력
- 알림 설정/API Key
- 시스템 파라미터/보안 정책(운영자)

## 5. 관리자 기준 사용 방법

### 5.1 Google 관리자 로그인

1. `Google 계정으로 로그인` 버튼 클릭
2. `kyubeom@gmail.com` 선택
3. Guest ENTER
4. 관리자 전용 메뉴 확인

### 5.2 관리자 콘솔

- 사용자 등록/승인/외부 사용자 관리

- 로그인/비밀번호/감사 정책 관리

## 8. 포털과 플랫폼 간 관계

### 8.1 포털 ↔ 데이터 플랫폼

- 포털이 하는 일: 데이터셋/모델 검색, 메타데이터 조회, 반출 신청, 사용량 조회
- 데이터 플랫폼이 하는 일: 데이터 수집/저장/가공/분석, 데이터 품질 관리, 리니지
- 주고받는 정보: 메타데이터, 검색 결과, 반출 파일, 사용량

### 8.2 포털 ↔ AI 플랫폼

- 포털이 하는 일: AI 작업환경 조회/신청, 모델 상태 조회, 성과물 반출 신청
- AI 플랫폼이 하는 일: 모델 개발/학습/평가/배포, LLMOps
- 주고받는 정보: 작업환경 정보, 모델 메타데이터, 학습/평가 상태, 반출 파일

### 8.3 포털 ↔ 클라우드/CMP

- 포털이 하는 일: 프로젝트/워크스페이스 신청, 크레딧/사용량 조회, 추가 자원/쿼터 신청
- 클라우드/CMP가 하는 일: GPU/CPU/스토리지 자원 할당, VM/컨테이너 실행, 과금/미터링
- 주고받는 정보: 자원 요청, 쿼터, 사용량, 과금 정보

### 8.4 포털 ↔ 인증/권한

- 포털이 하는 일: 로그인/SSO, 메뉴/권한 제어, 사용자/그룹/테넌트 조회
- 인증/권한이 하는 일: 사용자/조직/역할/테넌트 관리, 세션 관리
- 주고받는 정보: 사용자 정보, 역할/그룹, 세션 토큰, 테넌트 정보

### 8.5 포털 ↔ 보안/K-RMF

- 포털이 하는 일: 반입·반출 신청/승인, K-RMF 증빙 등록/조회, 감사로그 조회
- 보안/K-RMF가 하는 일: 반출 통제, 증빙 관리, 감사 로그 수집, DLP
- 주고받는 정보: 승인 요청/결과, 증빙 파일, 감사 이력

## 10. 현재 구현 수준과 후속 연동 범위

| 구분 | 현재 구현 수준 | 후속 연동 범위 |
|------|----------------|----------------|
| 포털 UI/메뉴/권한 | 화면 구현 완료 | Keycloak role/group claim 기반 메뉴 제어 |
| 통합검색 | OpenSearch proxy 연동, 샘플 데이터 fallback | 운영 OpenSearch 인스턴스, 권한 기반 필터 |
| 데이터/AI/클리우드 플랫폼 연계 | 설계안/후보 목록 기반 | 실제 API 명세 확정 및 연동 개발 |
| 반입·반출 승인 workflow | 화면 구현 완료 | 파일 저장소, 전자결재, 보안 검토 API |
| 감사/K-RMF 증빙 | 설계안/샘플 데이터 기반 | 중앙 감사 로그 시스템, K-RMF 평가 DB |
| 요구사항/API 연계현황 | 화면 구현 완료 | RFP 확정 시 데이터 갱신, 인터페이스 정의서 작성 |
| 사용자/권한 관리 | 화면 구현 완료 | Keycloak Admin API, 조직/부서 DB |
| 크레딧/사용량 | 화면 구현 완료 | AI/큐브/클우드 사용량 수집 API, 차감 enforcement |
