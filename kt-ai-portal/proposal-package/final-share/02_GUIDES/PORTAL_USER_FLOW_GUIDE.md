# 포털 사용자 흐름 가이드

> 국방지능형플랫폼포털의 주요 사용자별 여정과 플랫폼 연계 흐름을 정리합니다.

## 1. 포털은 "입구"입니다

국방지능형플랫폼포털은 데이터 플랫폼, AI 플랫폼, 지능형 클라우드/CMP를 직접 대체하지 않습니다.  
사용자가 하나의 접점에서 각 플랫폼을 안전하게 접근·신청·조회·승인·연계할 수 있도록 지원하는 **통합 진입점이자 업무 오케스트레이션 계층**입니다.

## 2. 사용자 유형별 여정

### 2.1 일반 사용자

- **목표**: 포털에 접속하여 공개된 데이터/모델/도구를 탐색하고 필요한 업무를 신청
- **사용 메뉴**: 통합 대시보드, 통합검색, 서비스/도구 카탈로그, 프로젝트/워크스페이스, 반입·반출 승인, 크레딧 관리, 마이페이지, 환경설정
- **흐름**: 접속 → Guest 또는 Google 로그인 → 대시보드 확인 → 통합검색/카탈로그 탐색 → 필요 시 프로젝트/반출/크레딧 업무 신청

### 2.2 데이터 엔지니어

- **목표**: 데이터셋을 등록·정제하고 프로젝트에 활용할 수 있도록 준비
- **사용 메뉴**: 통합검색, 서비스/도구 카탈로그, 프로젝트/워크스페이스
- **연계 플랫폼**: 데이터 플랫폼, 인증/권한
- **흐름**: 데이터 플랫폼 작업환경/도구 조회 → 데이터셋 등록/정제 → 메타데이터 및 품질 결과를 포털에 반영 → 프로젝트에서 활용 가능하도록 연계

### 2.3 데이터 사이언티스트

- **목표**: 데이터셋을 탐색·분석하고 AI 모델 개발에 활용
- **사용 메뉴**: 통합검색, 서비스/도구 카탈로그, 프로젝트/워크스페이스, 반입·반출 승인
- **연계 플랫폼**: 데이터 플랫폼, AI 플랫폼, 지능형 클라우드/CMP
- **흐름**: 통합검색 → 데이터 플랫폼 메타데이터 조회 → 데이터셋 상세/보안등급 확인 → 프로젝트 활용 신청 → AI/데이터 작업환경에서 분석 → 반출 필요 시 승인 workflow

### 2.4 AI 개발자

- **목표**: AI 작업환경에서 모델을 학습·평가·배포하고 성과물 반출
- **사용 메뉴**: 프로젝트/워크스페이스, 서비스/도구 카탈로그, 크레딧 관리, 반입·반출 승인
- **연계 플랫폼**: AI 플랫폼, 데이터 플랫폼, 지능형 클라우드/CMP, 보안/K-RMF
- **흐름**: 프로젝트 생성 → AI 작업환경/자원 신청 → 클라우드/CMP 자원 할당 → AI 플랫폼에서 학습/평가 → 포털 상태/사용량 조회 → 성과물 반출 신청/승인

### 2.5 프로젝트 관리자

- **목표**: 프로젝트 생애주기, 자원, 크레딧, 멤버 관리
- **사용 메뉴**: 프로젝트/워크스페이스, 크레딧 관리, 반입·반출 승인, 마이페이지
- **연계 플랫폼**: 지능형 클라우드/CMP, AI 플랫폼, 데이터 플랫폼
- **흐름**: 프로젝트 현황 조회 → 자원/크레딧 사용량 모니터링 → 추가 자원/쿼터 신청 → 멤버 권한 관리 → 반입·반출 승인/반려

### 2.6 군별 관리자

- **목표**: 육해공군 테넌트 단위 쿼터·사용량·권한 통제
- **사용 메뉴**: 육해공군 관리, 관리자 콘솔, 크레딧 관리
- **연계 플랫폼**: 인증/권한, 지능형 클라우드/CMP
- **흐름**: 군별 조직/사용자/프로젝트 범위 확인 → 인증/권한 시스템에서 권한 조회 → 쿼터/사용량 조회 → 권한 위임/회수 → 잔여량/장애 현황 확인

### 2.7 보안 관리자

- **목표**: 반입·반출 승인 및 K-RMF 증빙·감사 관리
- **사용 메뉴**: 반입·반출 승인, K-RMF 증빙관리, 관리자 콘솔
- **연계 플랫폼**: 보안/K-RMF, 인증/권한
- **흐름**: 반출 신청 접수 → 보안등급/승인권자 확인 → 승인/반려 처리 → 증빙 자료 및 감사 로그 연계 → 정기 K-RMF 평가 자료 활용

### 2.8 제안/사업관리자 (관리자)

- **목표**: RFP 요구사항 대응과 API 연계현황 추적·보고
- **사용 메뉴**: 요구사항 대응현황, 플랫폼 API 연계현황, 업무흐름/연계 시나리오
- **연계 플랫폼**: 데이터 플랫폼, AI 플랫폼, 지능형 클라우드/CMP, 보안/K-RMF
- **흐름**: SFR별 구현현황 조회 → 메뉴 대응현황 확인 → 포털-플랫폼 API 후보 검토 → 업무흐름 시나리오 검토 → CSV 추출 → 제안/보고 자료 작성

## 3. 플랫폼 연계 흐름 요약

```text
[사용자] → 포털(인증/권한) → 메뉴/신청/승인/조회
    ↓
데이터 플랫폼 ←→ AI 플랫폼 ←→ 지능형 클라우드/CMP
    ↓
보안/K-RMF(승인·감사·증빙)
```

- 포털은 플랫폼들 사이의 **연계 관문(gateway)** 역할을 합니다.
- 실제 데이터/모델/자원 처리는 각 플랫폼에서 수행됩니다.
- 모든 주요 행위는 감사 로그로 남으며, K-RMF 증빙 자료로 활용됩니다.
