# 국방지능형플랫폼포털 발표자 스크립트

> 32.2단계 기능흐름 RFP 대응 발표자료용 스크립트입니다. 슬라이드별 30초~1분 분량입니다.

## 1. 시작 멘트

"안녕하십니까. 국방지능형플랫폼포털 제안 발표를 시작하겠습니다. 본 발표에서는 포털의 전체 기능 흐름, 사용자 유형별 이용 방식, 그리고 RFP 21개 SFR과의 대응 관계를 중심으로 설명드리겠습니다."

## 2. 포털은 ‘통합 진입점’입니다

"먼저 포털의 역할부터 말씀드리겠습니다. 국방지능형플랫폼포털은 데이터 플랫폼, AI 플랫폼, 지능형 클라우드/CMP를 직접 대체하는 시스템이 아닙니다. 사용자가 하나의 접점에서 각 플랫폼을 안전하게 접근·신청·조회·승인·연계할 수 있도록 지원하는 통합 진입점이자 업무 오케스트레이션 계층입니다. 데이터 플랫폼은 데이터 창고이자 정리 공장, AI 플랫폼은 모델을 만드는 연구실, 클라우드/CMP는 GPU와 서버를 빌려주는 자원센터라고 비유할 수 있습니다. 포털은 이 세 공간을 하나의 안내소·신청 창구·현황판으로 연결합니다."

## 3. 전체 체계 개요

"전체 체계를 보시면, 중앙에 포털이 있고 데이터 플랫폼, AI 플랫폼, 지능형 클라우드/CMP, 인증·권한, 보안·K-RMF가 연결되어 있습니다. 포털은 단일 접점과 권한 통제, 업무 workflow 오케스트레이션을 담당하고, 실제 데이터 처리나 모델 학습, 자원 생성은 각 플랫폼에서 수행됩니다."

## 4. 사용자 유형별 사용 흐름

"사용자는 크게 일반 사용자와 관리자로 나뉩니다. 일반 사용자는 접속 후 대시보드를 확인하고, 통합검색과 카탈로그로 필요한 데이터·도구를 탐색한 뒤 프로젝트·반출·크레딧 업무를 신청합니다. 반면 보안 관리자는 반입·반출 승인과 K-RMF 증빙을, 군별 관리자는 테넌트 쿼터와 사용량을, 사업관리자는 요구사항 대응현황과 API 연계현황을 추적합니다."

## 5. 전체 메뉴 구조

"메뉴는 포털 공통, 프로젝트 운영, 관리·보안, 사용자·조직, 관리자 전용 영역으로 구성됩니다. 통합 대시보드, 통합검색, 서비스·도구 카탈로그, 제안 게시판은 누구나 사용하고, 프로젝트·반출·크레딧은 업무 담당자가, 관리자 전용 메뉴는 사업관리자와 보안·운영 담당자가 사용합니다."

## 6. RFP 21개 SFR 대응 총괄

"RFP의 21개 SFR은 포털 메뉴와 명확히 매핑됩니다. SFR-001 메인 포털은 대시보드, SFR-002는 로그인, SFR-003~006은 관리자 콘솔, SFR-007~008은 서비스·도구 카탈로그, SFR-009~011은 반입·반출 승인, SFR-012는 플랫폼 연동, SFR-013은 제안 게시판, SFR-014~015는 카탈로그와 통합검색, SFR-016~018은 프로젝트·크레딧·워크스페이스, SFR-019~021은 마이페이지·환경설정·육해공군 관리에 대응합니다."

## 7. 통합 대시보드

"첫 번째 기능 장표입니다. 통합 대시보드는 SFR-001 메인 포털과 SFR-012 플랫폼 연동에 대응합니다. 데이터셋·AI 모델·프로젝트·크레딧·K-RMF·시스템 상태를 한눈에 보여주며, 공지사항과 Quick Links로 메뉴 접근성을 높입니다. 현재는 화면 구현이 완료되었고, 후속으로 실시간 플랫폼 상태 API와 개인화 위젯을 연동할 예정입니다."

## 8. 로그인 / 인증

"로그인은 SFR-002에 대응합니다. 접근코드 또는 Google 계정으로 로그인할 수 있으며, Firebase Auth 연동을 완료했고 Keycloak OIDC 연동도 확인했습니다. 운영 환경에서는 SSO, MFA, PKI·MPKI 연동을 고려할 수 있습니다."

## 9. 관리자 콘솔

"관리자 콘솔은 SFR-003~006 사용자·권한·정책·메뉴 관리에 대응합니다. 사용자 등록과 승인, 역할·그룹·권한 매트릭스, 메뉴·프로그램 관리, 로그인·비밀번호·세션 정책, 감사로그를 한 화면에서 관리합니다. 후속으로 Keycloak Admin API와 조직·부서 DB, 정책 엔진을 연동할 예정입니다."

## 10. 서비스/도구 카탈로그

"서비스·도구 카탈로그는 SFR-007·008·014에 대응합니다. AI·데이터 개발에 필요한 분석·개발·데이터·시각화·라벨링 도구를 조회·선택·요청할 수 있습니다. OpenMetadata·Docker·PyPI 실제 연동과 도구 요청 workflow는 후속 연동 범위입니다."

## 11. 반입·반출 승인

"반입·반출 승인은 SFR-009~011·012에 대응합니다. 데이터 반입·반출에 대한 신청·승인·보안 검토 workflow를 지원하며 이력을 관리합니다. 실제 승인 workflow, 파일 저장소, 보안 검토 API, 감사로그 DB 연결이 후속 과제입니다."

## 12. 통합검색

"통합검색은 SFR-014·015에 대응합니다. 데이터셋·모델·도구·문서를 보안등급과 유형 중심으로 통합 검색합니다. OpenSearch proxy 연동을 확인했으며, 운영 OpenSearch 인스턴스와 권한 기반 결과 필터를 후속으로 연동할 예정입니다."

## 13. 프로젝트/워크스페이스

"프로젝트·워크스페이스는 SFR-016·018에 대응합니다. AI 연구·개발 프로젝트를 등록·조회하고 멤버·자원을 관리하며 워크스페이스 생성을 신청합니다. 후속으로 프로젝트 DB·API, Keycloak 그룹, CMP·Kubernetes 워크스페이스 연동이 필요합니다."

## 14. 크레딧 관리

"크레딧 관리는 SFR-016·017·018에 대응합니다. 프로젝트별 크레딧 잔액·사용량을 모니터링하고 충전·사용 이력과 부족 알림을 제공합니다. AI·큐브·클우드 사용량 수집 API와 크레딧 차감 enforcement는 후속 연동 범위입니다."

## 15. K-RMF 증빙관리

"K-RMF 증빙관리는 SFR-002·004에 대응합니다. K-RMF 평가 항목별 증빙 자료를 등록·조회하고 보안 미흡사항 조치를 관리합니다. K-RMF 평가 DB, 증빙 파일 저장소, 감사이력 연동을 후속으로 진행합니다."

## 16. 마이페이지 / 환경설정 / 육해공군 관리

"이 장표는 SFR-019~021을 함께 보여줍니다. 마이페이지는 개인 정보·활동·API Key 관리, 환경설정은 시스템·보안·자원 설정, 육해공군 관리는 군별 테넌트·쿼터·사용량·권한 위임을 담당합니다. 운영에서는 Keycloak·DB, 설정 DB, Kubernetes·OpenStack·CMP quota 연동이 필요합니다."

## 17. 제안 게시판

"제안 게시판은 SFR-013에 대응합니다. 사용자가 AI·데이터·도구·정책 아이디어를 제안하고 관리자가 공감·추천·댓글을 통해 검토할 수 있습니다. 후속으로 제안 DB, 알림·메일, 승인 workflow를 연동할 예정입니다."

## 18. 요구사항 대응현황

"관리자 추적 기능을 설명드리겠습니다. 요구사항 대응현황은 SFR-001~021 전체를 메뉴·SFR·기능 단위로 추적하고 CSV로 추출합니다. RFP 확정 후 데이터를 갱신하여 사업관리자용 추적 도구로 활용할 수 있습니다."

## 19. 플랫폼 API 연계현황

"플랫폼 API 연계현황은 SFR-012 플랫폼 연동에 대응합니다. 데이터·AI·클리우드·인증·보안 플랫폼 간 연계 후보를 API·이벤트·파일 단위로 정의하고 관리합니다. 현재는 설계안·후보 목록 기반이며, 실제 연동은 각 플랫폼 API 명세 확정 후 개발됩니다."

## 20. 업무흐름/연계 시나리오

"업무흐름·연계 시나리오는 7개 사용자 여정과 7개 업무흐름을 시각화합니다. 단계별로 사용자 행위, 호출 메뉴, 연계 플랫폼, API·RFP 매핑을 보여주어 복잡한 연계를 쉽게 이해할 수 있도록 돕습니다."

## 21. 대표 흐름 1 — 데이터셋 탐색 및 활용 신청

"첫 번째 대표 흐름입니다. 사용자가 통합검색으로 데이터셋을 탐색하고 보안등급과 메타데이터를 확인한 뒤, 프로젝트에서 활용을 신청합니다. 데이터 플랫폼 작업환경에서 분석·가공한 결과물은 반입·반출 승인을 거쳐 반출됩니다."

## 22. 대표 흐름 2 — AI 작업환경 생성 및 모델 개발

"두 번째 흐름입니다. 사용자가 서비스·도구 카탈로그에서 AI 도구를 선택하고, 프로젝트에 자원·도구를 신청하면 지능형 클라우드/CMP에서 자원이 할당됩니다. AI 플랫폼에서 학습·평가·배포를 수행하고, 크레딧 관리에서 사용량과 잔여량을 모니터링합니다."

## 23. 대표 흐름 3 — 반입·반출 승인 및 감사 추적

"세 번째 흐름입니다. 반입·반출 승인 메뉴에서 신청을 등록하면 보안등급과 승인권자에 따라 자동 분기됩니다. 보안 관리자가 승인·반려 처리하면 이력이 감사로그로 축적되고, K-RMF 증빙관리에서 평가 자료로 활용됩니다."

## 24. 대표 흐름 4 — 크레딧 기반 자원 사용량 관리

"네 번째 흐름입니다. 프로젝트별 크레딧 잔액을 확인하고 GPU·CPU·스토리지 사용량을 모니터링합니다. 잔여량이 부족하면 추가 충전을 신청하고, 군별 관리자는 쿼터와 사용량을 조회한 뒤 자원 회수·재배치를 결정합니다."

## 25. 포털 — 데이터 플랫폼 연계

"포털과 데이터 플랫폼의 연계를 정리하면, 데이터 플랫폼이 데이터 수집·저장·가공·분석을 담당하고, 포털은 데이터셋·도구 검색, 반입·반출 신청, 프로젝트 연계를 오케스트레이션합니다. 실제 데이터 처리는 데이터 플랫폼에서 수행됩니다."

## 26. 포털 — AI 플랫폼 연계

"포털과 AI 플랫폼의 연계입니다. AI 플랫폼은 모델 개발·학습·배포를, 포털은 AI 작업환경·도구 신청, 프로젝트 연계, 성과물 반출 승인을 관리합니다. 실제 모델 학습과 배포는 AI 플랫폼에서 수행됩니다."

## 27. 포털 — 지능형 클라우드/CMP 연계

"포털과 지능형 클라우드/CMP의 연계입니다. 클라우드/CMP는 GPU·서버·스토리지 자원과 쿼터를, 포털은 프로젝트·워크스페이스 생성 신청, 크레딧 할당, 사용량 모니터링, 군별 쿼터 통제를 관리합니다. 실제 자원 생성과 과금은 클라우드/CMP에서 수행됩니다."

## 28. 현재 구현 수준과 후속 연동 범위

"현재 구현 수준을 요약하면, 19개 핵심 화면의 UI·UX 구현이 완료되었고, 관리자 전용 기능과 OpenSearch·OpenMetadata·Keycloak 연동도 확인했습니다. 데이터 기반은 샘플 데이터로 화면 검증을 마쳤으며, 후속으로 실제 DB·API·Keycloak Admin·Kubernetes·OpenStack·CMP·파일 저장소 연동과 감사로그 DB 구축이 필요합니다."

## 29. 기대효과 및 마무리

"기대효과입니다. RFP 21개 SFR과 163개 기능목록을 화면과 명확히 매핑하고, 사용자 유형별 업무흐름을 시각적으로 제시합니다. 포털과 데이터·AI·클리우드 플랫폼의 역할 경계를 명확히 구분하고, 구현 수준과 후속 연동 범위를 투명하게 공유합니다. 이 자료는 제안 발표는 물론 사업 착수 후 상세설계의 기반 자료로 활용될 것입니다. 발표를 마치겠습니다. 감사합니다."
