# 포털 관리자 기능 사용 설명서

> 관리자(Google 로그인 관리자 또는 관리자 전용 플래그 모드)가 사용하는 메뉴와 기능을 정리합니다.

## 1. 관리자 로그인 방법

### 1.1 Google 관리자 로그인

1. 포털 접속
2. `Google 계정으로 로그인` 버튼 클릭
3. `kyubeom@gmail.com` 계정 선택
4. Backstage 로그인 화면에서 `Guest ENTER` 클릭
5. 왼쪽 메뉴에 관리자 전용 항목 표시 확인

### 1.2 관리자 전용 플래그 모드

Access Code(`ictway`) 로그인 후 브라우저 콘솔에서 실행:

```js
sessionStorage.setItem('__kt_ai_portal_admin_preview__', 'true');
location.reload();
```

- 운영 환경에서는 사용하지 않음
- 제안/검증 시 관리자 화면 미리보기용

## 2. 관리자 전용 메뉴

| 메뉴 | 라우트 | 목적 | 주요 기능 |
|------|--------|------|-----------|
| 관리자 콘솔 | `/admin-console` | 사용자·권한·정책·감사 중앙 관리 | 사용자 등록 신청/승인, 사용자/외부 사용자 관리, 권한/RBAC, 로그인/비밀번호 정책, 감사 로그, 메뉴/프로그램 관리 |
| 요구사항 대응현황 | `/requirement-coverage` | RFP/SFR/기능 단위 구현 현황 추적 | 메뉴 대응현황, SFR 대응현황, 기능 대응현황, 변경이력, 질의사항, CSV 다운로드 |
| 플랫폼 API 연계현황 | `/platform-api-integration` | 포털-플랫폼 연계 후보 관리 | 연계 후보 목록, API/이벤트/파일 구분, 플랫폼/메뉴/SFR 매핑, CSV 다운로드 |
| 업무흐름/연계 시나리오 | `/workflow-scenarios` | 사용자/플랫폼 관점 업무흐름 시각화 | 포털 역할 요약, 7개 사용자 여정, 7개 업무흐름 시나리오 |

## 3. 관리자 콘솔 상세

### 3.1 사용자 관리

- 사용자 등록 신청 목록/상세/승인/반려
- 사용자/외부 사용자 목록 및 상세 관리
- 조직/부서 관리
- 사용자 상태 변경 이력

### 3.2 권한/RBAC

- 역할/그룹 관리
- 역할별 권한 매트릭스
- 사용자/그룹 권한 매핑
- 메뉴/프로그램 관리

### 3.3 정책/감사

- 로그인 정책(중복 로그인, 자동 로그아웃, 세션 타임아웃)
- 비밀번호 정책(복잡도, 만료, 계정 잠금)
- 감사 로그 대시보드
- 로그인/로그아웃/설정 변경 이력

## 4. 요구사항 대응현황 사용법

1. 상단 요약 카드에서 전체 메뉴/화면구현/부분구현/후속개발 건수 확인
2. `메뉴 대응현황` 탭에서 각 메뉴가 어떤 SFR과 RFP를 대응하는지 확인
3. `SFR 대응현황` 탭에서 21개 SFR별 진척률과 영향도 확인
4. `기능 대응현황` 탭에서 163개 기능목록의 구현 상태 확인
5. `변경이력/질의사항` 탭에서 RFP 변경 이력과 검토 질의 확인
6. `메뉴 현황 CSV`, `기능 현황 CSV` 버튼으로 보고 자료 추출

## 5. 플랫폼 API 연계현황 사용법

1. 연계 후보 목록 조회
2. 각 후보의 연계 방식(API/이벤트/파일), 연계 플랫폼, 관련 메뉴/SFR 확인
3. `CSV 다운로드`로 연계 설계안 공유 및 검토
4. 실제 연동 개발 시 인터페이스 정의서 작성의 기초 자료로 활용

## 6. 업무흐름/연계 시나리오 사용법

1. `포털 역할 요약` 탭에서 포털과 각 플랫폼의 책임 경계 확인
2. `사용자 여정` 탭에서 7개 역할별 목표/메뉴/플랫폼/산출물 확인
3. `업무흐름 시나리오` 탭에서 7개 시나리오의 단계별 수행 주체/메뉴/플랫폼/API/RFP 확인

## 7. 관리자 권한 보안 원칙

- 관리자 전용 메뉴는 `visibleTo: 'admin'`과 `AdminOnlyGuard`로 제어
- 일반 사용자는 메뉴 미노출 및 직접 URL 접근 차단
- 관리자 이메일은 `app.auth.adminEmails` 설정값으로 제어
- 운영 환경에서는 Keycloak OIDC role/group claim 기반으로 전환 권장
