# 요구사항 대응현황 관리자 가이드

> 보안등급: 낮음(낮)

## 개요

`요구사항 대응현황` 메뉴는 RFP 요구사항(SFR-001~SFR-021)과 포털 UI 구현 현황을 **메뉴 / SFR / 기능** 단위로 추적할 수 있는 관리자 전용 화면입니다.

- **경로**: `/requirement-coverage`
- **별칭(legacy)**: `/requirement-progress` (동일 화면)
- **접근 권한**: `visibleTo: 'admin'` + `AdminOnlyGuard`
  - 일반 사용자에게는 Sidebar에 노출되지 않으며, 직접 URL 접근 시에도 차단됩니다.

## 화면 구성

화면 상단에는 전체 메뉴 수, 화면구현/부분구현/후속·미구현 항목 수를 요약 카드로 보여줍니다.

### 1. 메뉴 대응현황 탭

모든 포털 메뉴(일반 + 관리자)에 대해 다음을 조회합니다.

| 항목 | 설명 |
|------|------|
| 메뉴/라우트 | 메뉴 이름과 실제 라우트 |
| 노출대상 | `전체` 또는 `관리자` |
| 관련 SFR | 해당 메뉴가 대응하는 SFR ID 목록 |
| 요약 | 화면구현/부분구현/후속·미구현 건수 |
| 관련 플랫폼 | 포털, 데이터 플랫폼, AI 플랫폼, 클라우드/CMP, 인증/권한, 보안/K-RMF 등 |
| 대응 근거 | RFP 매핑 이유 |

아코디언을 펼치면 각 메뉴의 **화면구현 / 부분구현 / 후속·미구현** 항목을 상세히 확인할 수 있습니다.

### 2. SFR 대응현황 탭

SFR 단위로 관련 메뉴와 진행률(화면구현 비율)을 확인합니다.

- SFR별로 연결된 메뉴 이름이 Chip으로 표시됩니다.
- LinearProgress로 해당 SFR 관련 기능의 화면구현 진행률을 시각화합니다.

### 3. 기능 대응현황 탭

견적용 기능목록 1~163개를 기준으로 다음을 조회합니다.

| 항목 | 설명 |
|------|------|
| 번호 | 기능목록 번호 |
| SFR ID | 매핑된 SFR(복수인 경우 콤마 구분) |
| 대분류 | 기능 분류 |
| 세부기능 | 기능 상세 설명 |
| 구현상태 | 화면구현 / 부분구현 / 후속개발 / 미구현 / 검토필요 |
| 관련 메뉴 | 해당 기능이 노출되는 화면 메뉴 |
| 플랫폼 연계 | API 연계 대상 플랫폼 존재 여부 |
| 후속조치 | 다음 단계 작업 |

### 4. 변경이력 탭

RFP 및 기능목록 변경 이력(`RequirementChangeHistory`)을 표시합니다.

### 5. 질의사항 탭

RFP 관련 검토 질의(`RequirementQuestion`)과 우선순위를 표시합니다.

## CSV 다운로드

상단 버튼을 통해 두 가지 CSV를 낮출할 수 있습니다.

- **메뉴 현황 CSV**: 메뉴 단위 대응 현황
- **기능 현황 CSV**: 기능목록 단위 대응 현황

CSV는 UTF-8(BOM)로 생성되며, Excel에서 한글 깨짐 없이 열 수 있습니다.

## 보안 및 운영 주의사항

- 본 메뉴는 **관리자 전용**입니다. production 배포 시 반드시 `AdminOnlyGuard`가 적용되어 있는지 확인하세요.
- CSV 다운로드 파일에는 기능 상세 정보가 포함되므로, 외부 유출에 주의하세요.
- mock 데이터 기반이므로 실제 RFP 확정 후 데이터를 갱신해야 합니다.


## 31단계 연계

- `업무흐름/연계 시나리오`(`/workflow-scenarios`) 화면에서 각 메뉴의 사용자 흐름과 플랫폼 연계 맥락을 함께 확인할 수 있습니다.
- `요구사항 대응현황`의 메뉴/SFR/기능 데이터는 `업무흐름/연계 시나리오`의 RFP 매핑 근거 자료로 활용됩니다.
