# 업무흐름/연계 시나리오 가이드

> 보안등급: 낮음(낮)

## 31단계 목적

본 문서는 `업무흐름/연계 시나리오` 화면(`/workflow-scenarios`)의 설계 가이드입니다.

평가자, 제안팀, 납품 후 운영/사업관리자가 각 메뉴를 볼 때 다음을 즉시 이해할 수 있도록 합니다.

- 이 메뉴가 왜 존재하는가
- 어떤 RFP(SFR) 요구사항을 만족하는가
- 데이터 플랫폼/AI 플랫폼/클리우드와 어떻게 연결되는가
- 업무 흐름상 다음 단계가 무엇인가

## 포털 역할 정의

국방지능형플랫폼포털은 데이터 플랫폼, AI 플랫폼, 지능형 클라우드/CMP를 직접 대체하지 않습니다.

포털은 **통합 진입점이자 업무 오케스트레이션 계층**으로, 다음 역할을 수행합니다.

- SSO/권한 기반 단일 접점
- 프로젝트/워크스페이스/자원/반입반출 신청 및 승인 workflow
- 데이터/AI/도구 카탈로그 통합 검색 및 조회
- 크레딧/사용량/쿼터 현황 조회
- K-RMF 증빙 및 감사추적 조회
- 요구사항/API 연계현황 관리

## 7개 업무흐름 시나리오

### SCN-001: 통합 포털 접속 및 권한 기반 플랫폼 진입

- **사용자**: 데이터 엔지니어, 데이터 사이언티스트, AI 개발자
- **관련 메뉴**: 통합 대시보드, 관리자 콘솔, 마이페이지
- **관련 플랫폼**: 포털, 인증/권한, 데이터 플랫폼, AI 플랫폼, 지능형 클라우드/CMP
- **관련 SFR**: SFR-001, SFR-002, SFR-003, SFR-005, SFR-006
- **요지**: 사용자가 포털에 로그인 → 권한/RBAC 확인 → 역할에 맞는 메뉴/플랫폼 링크 제공 → 데이터/AI/클리우드 메뉴 진입

### SCN-002: 데이터셋 탐색 및 활용 신청

- **사용자**: 데이터 사이언티스트, AI 개발자
- **관련 메뉴**: 통합검색, 서비스/도구 카탈로그, 프로젝트/워크스페이스
- **관련 플랫폼**: 포털, 데이터 플랫폼, OpenSearch/OpenMetadata
- **관련 SFR**: SFR-012, SFR-014, SFR-015, SFR-016
- **요지**: 통합검색 → 데이터 플랫폼 메타데이터 조회 → 데이터셋 상세/보안등급 확인 → 프로젝트 활용 신청 → 승인 → 데이터 플랫폼 접근 권한 부여

### SCN-003: AI 작업환경 생성 및 모델 개발

- **사용자**: AI 개발자
- **관련 메뉴**: 프로젝트/워크스페이스, 서비스/도구 카탈로그, 크레딧 관리
- **관련 플랫폼**: 포털, AI 플랫폼, 데이터 플랫폼, 지능형 클라우드/CMP
- **관련 SFR**: SFR-007, SFR-016, SFR-017, SFR-018
- **요지**: 프로젝트 생성 → AI 작업환경/자원 신청 → 클라우드/CMP에서 실행환경 생성 → AI 플랫폼에서 모델 학습/평가 → 포털에서 상태/사용량 조회

### SCN-004: 크레딧 기반 자원 사용량 모니터링

- **사용자**: 프로젝트 관리자, 군별 관리자
- **관련 메뉴**: 크레딧 관리, 육해공군 관리, 프로젝트/워크스페이스
- **관련 플랫폼**: 포털, 지능형 클라우드/CMP, 인증/권한
- **관련 SFR**: SFR-016, SFR-017, SFR-018, SFR-021
- **요지**: 프로젝트별 사용량/크레딧 조회 → 잔액/추이/예상 소진 확인 → 군별 쿼터/사용량 조회 → 추가 자원/쿼터 신청

### SCN-005: 성과물 반출 승인 및 감사 추적

- **사용자**: AI 개발자, 보안 관리자, 프로젝트 관리자
- **관련 메뉴**: 반입·반출 승인, K-RMF 증빙관리, 관리자 콘솔
- **관련 플랫폼**: 포털, AI 플랫폼, 데이터 플랫폼, 보안/K-RMF
- **관련 SFR**: SFR-004, SFR-009, SFR-010, SFR-011
- **요지**: 반출 신청 → 보안/K-RMF 승인 workflow → 승인/반려 → AI/데이터 플랫폼 파일 반출 → 감사 로그 및 K-RMF 증빙 생성

### SCN-006: 군별 관리자 권한 및 멀티테넌트 관리

- **사용자**: 군별 관리자
- **관련 메뉴**: 육해공군 관리, 관리자 콘솔
- **관련 플랫폼**: 포털, 인증/권한, 지능형 클라우드/CMP
- **관련 SFR**: SFR-005, SFR-016, SFR-017, SFR-021
- **요지**: 군별 조직/사용자/프로젝트 범위 확인 → 인증/권한 연계 → 쿼터/사용량 조회 → 권한 위임/회수 → 프로젝트 현황/잔여량 확인

### SCN-007: RFP 요구사항 대응 및 API 연계 검토

- **사용자**: 제안/사업관리자
- **관련 메뉴**: 요구사항 대응현황, 플랫폼 API 연계현황, 업무흐름/연계 시나리오
- **관련 플랫폼**: 포털, 데이터 플랫폼, AI 플랫폼, 지능형 클라우드/CMP, 보안/K-RMF
- **관련 SFR**: SFR-001, SFR-012, SFR-014, SFR-016, SFR-017, SFR-018, SFR-021
- **요지**: SFR별 구현현황 조회 → 메뉴 대응현황 확인 → 포털-플랫폼 API 후보 확인 → 업무흐름 시나리오 검토 → CSV 추출

## PoC 구현 수준과 후속 연동 범위

현재 `/workflow-scenarios` 화면은 mock data 기반입니다.

| 구분 | PoC 구현 | 후속 연동 |
|------|----------|-----------|
| 포털 UI/메뉴/권한 | 화면구현 | Keycloak role/group claim 기반 메뉴 제어 |
| 데이터/AI/클리우드 플랫폼 연계 | Mock/설계안 | 실제 API 명세 확정 및 연동 개발 |
| 반입·반출 승인 workflow | 화면구현 | K-RMF 전자결재 연동 |
| 감사/K-RMF 증빙 | 설계안 | 중앙 감사 로그 시스템 연계 |
| 요구사항/API 연계현황 | 화면구현 | RFP 확정 시 데이터 갱신 |
