# 최종 요구사항 추적표 (Final Requirement Traceability Matrix)

> 견적용 기능목록 1~155 전체에 대한 화면 대응 및 구현 상태 추적표입니다.  
> 본 표는 `docs/REQUIREMENT_SCREEN_COVERAGE.md`와 함께 제안서 및 시연 자료 작성에 활용합니다.  
> **RFP ID**는 외부 견적용 기능목록을 참조하며, 본 문서에서는 기능번호를 RFP ID로 매핑하였습니다.

## 범례

| 상태 | 의미 |
|------|------|
| 화면 구현 완료 | 사용자가 브라우저에서 확인할 수 있는 화면/컴포넌트가 존재 |
| 일부 구현 | 핵심 UI는 있으나 세부 흐름(승인, 알림, 연동 등)은 미완성 |
| PoC 구현 | 데모/시연용 mock 데이터 기반 동작 |
| 문서화 | 화멸 설계서 또는 정책 문서로 정의됨 |
| 미구현 | 현재 단계에서 화면 또는 로직 없음 |

## 화면 기준 충족도

| 등급 | 의미 |
|------|------|
| 90% | 핵심 화면 완성, 시연 가능 |
| 80% | 주요 화면 완성, 일부 세부 동작 필요 |
| 70% | 화면 구조 완성, mock 기반 |
| 60% | 화면 존재, 낮은 fidelity |
| 50% | 화면 초안 또는 문서 수준 |
| 30% | 일부 컴포넌트만 존재 |
| 0%  | 미구현 |
