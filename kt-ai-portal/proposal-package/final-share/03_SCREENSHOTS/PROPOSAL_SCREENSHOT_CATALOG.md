## 추가 캡처 권장 사항

- **관리자 콘솔 요약 카드 확대 캡처**: 등록 신청 대기/승인 대기/외부 사용자/활성 사용자 수치를 강조할 때 유용합니다.
- **육해공군 관리 요약 카드 확대 캡처**: 군별 프로젝트 수, GPU 할당/사용량, 쿼터 변경 대기, 과다 사용 경고를 강조할 때 유용합니다.
- **서비스/도구 카탈로그 도구 상세 화면**: 특정 도구(Jupyter, Label Studio 등) 선택/요청 흐름을 보여줄 때 유용합니다.
- **크레딧 관리 사용량 차트**: GPU/CPU 사용량 시각화를 강조할 때 유용합니다.
- **Sidebar 전체 메뉴 강조 캡처**: 한글 메뉴를 보여주는 데 유용합니다.

## 34단계 활용 반영

- 33.1단계 UI 정리(시연 배너 제거, 외부 운영도구 관리자 전용 이동)를 반영하여 01~14, 17~19를 production URL에서 재촬영.
- `OpenMetadata Catalog`, `OpenSearch Dashboards` 일반 장표 캡처는 제거하고, 대신 관리자 콘솔 `플랫폼 운영도구` 탭 캡처를 추가.
- 각 캡처는 `docs/SCREENSHOT_CAPTIONS.md`에 RFP ID, 한 줄 설명, 발표 강조 포인트, 후속 연동 포인트를 포함하여 보완.
- 발표자 스크립트 및 쉬운 설명 자료는 기존 32.2단계 산출물을 유지하되, 캡처 교체에 따라 발표 문구에서 외부 운영도구 위치를 관리자 전용으로 수정.
