# SER-002~SER-008 K-RMF 매핑

> 최종공고문 260723_v1의 SER-002~SER-008(K-RMF 통제·증빙·인가) 요구사항을 포털 K-RMF 증빙관리 구조에 매핑합니다.  
> 포털은 K-RMF 인가 결정을 내리지 않으며, 통제항목 이행 현황과 증빙 자료를 체계적으로 관리하는 도구를 제공합니다.

|---------|---------------|-----------|----------------------|-----------|

## 2. K-RMF 통제항목 이행관리 구조

### 2.1 계층 구조

- **대분류**: 접근통제, 암호화, 감사, 데이터 보호, 운영 보안, 물리/환경 보안 등 K-RMF 대분류
- **중분류**: 통제 항목(예: 접근통제-1, 암호화-1)
- **세분항목**: 포털 기능/메뉴/플랫폼 연계와 매핑된 세부 점검 항목
- **이행 상태**: `미이행`, `계획 수립`, `증빙 제출`, `내부 검토`, `평가 완료`, `인가 완료`
- **담당자**: 포털 운영자, 보안 담당자, 플랫폼 담당자, 타 수행사 담당자

### 2.2 포털 매핑 예시

| K-RMF 통제 항목 | 대상 포털 기능/메뉴 | 증빙 자료 예시 | 담당 |
|-----------------|---------------------|----------------|------|
| 접근통제 | Keycloak OIDC, RBAC, 메뉴/데이터 권한 | 권한 매트릭스, 역할 정의서, 로그인 정책 | 포털 운영/보안 |
| 암호화 | 비밀번호 정책, 반출 파일 전송 | 비밀번호 정책 문서, TLS/암호화 설정 | 포털 운영/보안 |
| 감사 및 추적 | 감사 로그, 사용자 활동 로그 | 감사 로그 샘플, 로그 보관 정책 | 포털 운영/보안 |
| 데이터 보호 | 반입·반출 승인, DLP 연계 | 반출 승인 이력, DLP 검사 기록 | 반출/보안 |
| 운영 보안 | 환경설정, 백업/복구 | 변경 이력, 백업 정책 | 포털 운영 |

## 3. 증빙자료 관리

### 3.1 증빙 자료 유형

- **정책/설계 문서**: 보안 정책, 권한 설계서, 아키텍처 문서
- **화면 캡처**: 설정 화면, 권한 화면, 감사 로그 화면
- **로그/감사 기록**: 사용자 로그인/로그아웃, 권한 변경, 반출 승인 이력
- **설정값/스크립트**: Keycloak realm 설정, 비밀번호 정책 파라미터, 백업 스크립트
- **외부 플랫폼 연계 자료**: API 연계 정의서, DLP 검사 결과, 암호화 적용 증빙

### 3.2 관리 흐름

1. 통제항목별 담당자 할당(SER-002/SER-003)
2. 이행 계획 등록(일정, 점검 방법, 상태)
3. 증빙자료 업로드(SER-004)
4. 내부 검토/승인 또는 반려(보안 담당자)
5. 미흡사항 조치 등록(SER-005)
6. 타 수행사 자료 수집 및 통합(SER-006)
7. 평가/인가 패키지 구성(SER-007)
8. 운영전환 자료 보관(SER-008)

### 3.3 보안/권한

- 증빙 자료 접근은 보안등급/역할 기반으로 제한(내부/비밀 등)
- 업로드/다운로드/승인/반려 시 감사 로그 자동 생성
- 외부 유출 방지를 위해 다운로드 시 보안 담당자 승인 workflow 적용(후속)

## 4. 평가/인가 대응

### 4.1 평가 준비

- **평가 기준 등록**: SER-007에서 요구하는 평가 항목, 기준, 점검 방법을 통제항목과 매핑.
- **평가 일정**: 내부 자체 평가 → 외부 평가(해당 시) → 인가 신청 일정 관리.
- **증빙 패키지**: 선택된 통제항목의 증빙자료를 ZIP/PDF로 패키징하여 평가기관 제출.
- **결과 관리**: 평가 결과(적합/부적합/조건부 적합)와 인가 상태를 통제항목별로 기록.

### 4.2 인가 후 조치

- 인가 완료 항목은 `운영전환 자료`로 이동(SER-008).
- 인가 조건부/부적합 항목은 `미흡사항`으로 전환하여 조치 계획 수립.
- 인가 이력은 감사 로그에 영구 보관.

## 5. 운영전환 자료

- **인가 완료 패키지**: 통제항목별 증빙자료, 평가 결과, 인가서 사본
- **운영 보안 절차**: 인가 후 변경관리, 접근권한 인수인계, 백업/복구 절차
- **담당자 인수인계**: 보안 담당자/운영자 변경 이력, 인수인계 확인서
- **후속 점검 계획**: 정기 재평가/점검 일정, 모니터링 항목

## 7. 후속 연동

- 보안/K-RMF 시스템에서 통제항목 기준 데이터를 API/파일로 수신하여 자동 매핑(SER-002).
- 중앙 감사 로그 시스템과 연계하여 증빙 자료로 활용(SER-004).
- 전자결재 시스템과 연계하여 증빙 승인/반려 workflow 자동화(SER-004).
- 평가기관 제출용 패키지 자동 생성 기능 개발(SER-007).
