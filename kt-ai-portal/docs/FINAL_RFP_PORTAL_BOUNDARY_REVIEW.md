# 최종공고문 260723_v1 포털 구현 범위 및 경계 검토

> 최종공고문 260723_v1 기준으로 국방지능형플랫폼포털이 직접 구현하는 범위, 연계 범위, 그리고 타 플랫폼이 제공하는 범위를 명확히 구분합니다.  
> 본 검토는 제안/사업 관리자가 포털의 책임 경계를 오해하지 않도록 하기 위한 자료입니다.

## 1. 목적

- 포털이 직접 구현해야 할 SFR-001~SFR-021 범위를 정리합니다.
- 포털이 연계만 수행하는 범위를 정의합니다.
- 데이터 플랫폼, AI 플랫폼, 클라우드/CMP, 보안/K-RMF 등 타 플랫폼의 제공 전제를 명시합니다.
- 포털 구현 범위에 포함되지 않는 항목을 명확히 제외하여 향후 분쟁/혼선을 방지합니다.

## 3. 포털 연계 범위

포털은 아래 기능에 대해 **화면/신청/승인/조회/증빙 관리**는 직접 수행하고, 실제 처리/엔진은 타 플랫폼과 연계합니다.

| 연계 분야 | 포털 역할 | 연계 대상 | 연계 방식 |
|-----------|-----------|-----------|-----------|
| 인증/권한 | SSO 로그인, 역할/그룹 조회, 권한 판단 | Keycloak/Firebase Auth | OIDC, REST API |
| AI 작업환경 | 도구 선택/요청, 상태 조회, 접속 링크 노출 | AI 플랫폼 | REST API |
| 데이터 작업환경 | 도구 선택/요청, 데이터셋 조회, 반출 파일 전송 | 데이터 플랫폼 | REST API, 파일(S3/SFTP) |
| 클라우드/CMP | 프로젝트/워크스페이스 생성 요청, 크레딧/사용량 조회 | 클라우드/CMP | REST API |
| 통합검색 | 검색 UI, 필터, 결과 노출 | OpenSearch / 데이터 플랫폼 | REST API/proxy |
| 메타데이터/카탈로그 | 메타데이터 조회, 계보/태그 노출 | OpenMetadata | REST API |
| 반입·반출 | 신청/승인 workflow, 이력 관리 | 보안/K-RMF, AI/데이터 플랫폼 | REST API, 파일, 이벤트 |
| K-RMF/감사 | 증빙 자료 등록/조회, 감사 로그 조회 | 보안/K-RMF, 중앙 로그 시스템 | 파일, 이벤트(Kafka/SSE) |
| 공지/알림 | 공지사항 등록/조회, 알림 수신 설정 | 알림 서비스(후속) | 이벤트 |

## 4. 타 플랫폼 제공 전제

| 플랫폼 | 제공해야 할 핵심 기능 | 포털에 노출되는 결과 예시 |
|--------|------------------------|----------------------------|
| **데이터 플랫폼** | 데이터 수집/저장/가공/분석, 데이터 카탈로그, 라벨링/비식별화, OpenSearch 색인 | 데이터셋 목록, 메타데이터, 검색 결과, 반출 파일 |
| **AI 플랫폼** | 모델 개발/학습/배포/추론, AI 작업환경, 모델 레지스트리 | AI 모델 목록, 학습 상태, 실증 결과, 접속 링크 |
| **지능형 클라우드/CMP** | 인프라/컴퓨팅/스토리지/네트워크, 쿼터/과금/크레딧 | 워크스페이스 생성 결과, 자원 사용량, 크레딧 잔액 |
| **보안/K-RMF** | 보안통제항목 정의, 증빙 검토, DLP, 감사 로그, 인가 결정 | K-RMF 통제항목, 증빙 상태, 인가 결과 |
| **인증/권한** | 사용자/조직/역할/테넌트, SSO, 세션, MFA | 로그인 세션, 역할/그룹, 권한 매트릭스 |

## 5. 제외 범위

아래 항목은 포털 직접 구현 범위에 **포함되지 않습니다**. 타 플랫폼 또는 별도 수행사에서 제공해야 합니다.

- 데이터 플랫폼 본체(데이터 레이크, ETL, 파이프라인, 데이터 카탈로그 엔진 등)
- AI 모델 학습/배포/추론 엔진 및 모델 레지스트리
- 클라우드/CMP 엔진(가상머신, Kubernetes, 오케스트레이션, 네트워크/스토리지 관리)
- Kafka, Spark, Trino, Ceph, HDFS, Vector DB 등 인프라/빅데이터 엔진
- 라벨링 엔진, 비식별화 엔진
- 실제 AI 모델 학습(데이터 준비, 하이퍼파라미터 튜닝, 모델 성능 평가)
- 실증 모델 정확도 보장(TER-008 실증 결과의 객관적 성능/정확도는 AI/데이터 플랫폼 및 과제 수행팀 책임)
- K-RMF 인가 결정 자체(포털은 증빙 자료 관리와 감사 이력 연계만 지원)
- 보안 검토/DLP 스캔/바이러스 검사 등 보안 엔진 본체

## 6. 경계 원칙

1. **대체 금지**: 포털은 위 제외 항목의 핵심 기능을 대체하지 않습니다.
2. **단일 접점 + 권한 통제**: 포털은 사용자의 진입점과 공통 권한/감사를 담당합니다.
3. **신청/승인 오케스트레이션**: 업무 workflow의 시작/승인/이력은 포털에서, 실제 자원 생성/파일 처리는 플랫폼에서 수행합니다.
4. **집계/조회 위주**: 포털은 플랫폼으로부터 현황/메타데이터를 조회하여 보여줍니다.
5. **감사 통합**: 모든 연계 호출은 포털 감사 로그에 남기며, 민감 연계는 K-RMF 검토를 거칩니다.
