# 제안 발표용 설명 문구

> 보안등급: 낮음(낮)

## 포털 역할 설명

> "국방지능형플랫폼포털은 데이터 플랫폼, AI 플랫폼, 지능형 클라우드/CMP를 직접 대체하는 시스템이 아닙니다. 포털은 사용자가 하나의 접점에서 각 플랫폼을 안전하게 접근·신청·조회·승인·연계할 수 있도록 지원하는 통합 진입점이자 업무 오케스트레이션 계층입니다."

> "본 포털은 개별 플랫폼 기능을 단순 링크로 나열하는 것이 아니라, 사용자 권한·프로젝트·워크스페이스·자원·반입반출·감사 흐름을 하나의 업무 절차로 연결하여 전군 공동활용 플랫폼의 운영 편의성과 통제성을 높입니다."

## 데이터 플랫폼과의 관계

> "데이터 수집·적재·정제·전처리·품질관리·리니지는 데이터 플랫폼의 핵심 역할입니다. 포털은 데이터 플랫폼의 메타데이터와 검색 결과를 조회하고, 데이터셋을 프로젝트에 활용할 수 있도록 신청·승인하는 연계 관문 역할을 수행합니다."

## AI 플랫폼과의 관계

> "AI 모델 학습·실험·평가·배포·서빙·LLMOps는 AI 플랫폼의 핵심 역할입니다. 포털은 AI 개발자가 프로젝트와 자원을 신청하면 AI 플랫폼의 작업환경으로 연결하고, 학습/평가 상태와 사용량을 한눈에 보여줍니다."

## 클라우드/CMP와의 관계

> "GPU/CPU/스토리지 자원 할당, VM/컨테이너 실행환경, 사용량 미터링은 지능형 클라우드/CMP의 핵심 역할입니다. 포털은 클라우드/CMP로부터 사용량과 쿼터를 조회하고, 필요 시 추가 자원/쿼터를 신청할 수 있도록 합니다."

## 요구사항 추적성 강조 문구

> "RFP의 21개 SFR과 163개 기능목록은 포털 메뉴, 화면, 플랫폼 연계 설계안과 명확히 매핑되어 있습니다. 관리자 전용 `요구사항 대응현황` 화면에서 메뉴/SFR/기능 단위로 구현 현황을 추적할 수 있습니다."

> "요구사항 대응현황은 제안/사업관리용 납품 후 관리자 기능으로, 일반 제안팀 사용자에게는 노출되지 않으며 직접 URL 접근도 차단됩니다."

## API 연계 설계 강조 문구

> "현재 PoC 단계에서 정의된 API/연계 후보는 실제 확정 명세가 아닙니다. 포털-플랫폼 연계는 사업 착수 후 상세설계에서 확정되며, `플랫폼 API 연계현황` 화면에서 설계안과 후속 확인사항을 체계적으로 관리합니다."

> "CSV 다운로드를 통해 요구사항 대응 현황과 API 연계 후보 목록을 제안서 및 검토 자료로 활용할 수 있습니다."

## 업무흐름 시나리오 강조 문구

> "`업무흐름/연계 시나리오` 화면은 데이터 엔지니어부터 군별 관리자, 보안 관리자, 사업관리자까지 각 사용자가 포털과 플랫폼을 어떻게 사용하는지 한눈에 보여줍니다."

> "각 시나리오는 단계별 수행 주체, 사용 메뉴, 연계 플랫폼, 교환 데이터, 관련 API, RFP 매핑 근거를 포함하여 평가자와 제안팀이 즉시 이해할 수 있도록 구성되어 있습니다."

## 보안/통제 강조 문구

> "모든 반출 활동은 포털을 통해 신청·승인되며, 승인 이력과 증빙 자료가 K-RMF 감사추적에 자동 연계됩니다."

> "육해공군별 관리자는 포털에서 조직·권한·쿼터·사용량을 통합 관리하며, 필요 시 권한을 위임합니다."
