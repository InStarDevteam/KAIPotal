# 요구사항 화면 대응 현황

## 목적

요구사항 PDF(견적용 기능목록 1~155)에 포함된 기능 중 현재 PoC 화면으로 대응된 영역과 미대응 영역을 최종 정리합니다.  
본 문서는 `docs/FINAL_REQUIREMENT_TRACEABILITY_MATRIX.md`와 함께 제안서 및 시연 자료 작성에 활용합니다.

## 주요 영역

- **메인 포털**: `Portal Dashboard`에서 Hero, 통합검색, 요약 카드, 공지/자산/프로젝트/반출/크레딧/K-RMF/시스템 상태/바로가기 제공
- **로그인/로그아웃**: Backstage `SignInPage`에서 Guest/Keycloak 선택, Keycloak OIDC 연동 완료
- **사용자 관리**: `관리자 콘솔 > 사용자 관리`에서 사용자 목록, 상태, 접근 서비스 등을 조회하고 소속/역할/서비스 설정 UI 제공
- **사용자 등록 승인**: `관리자 콘솔 > 사용자 등록 신청`에서 본인확인 상태, 상세 정보, 승인/반려/보완요청/재신청 mock workflow 제공
- **외부 사용자 관리**: `관리자 콘솔 > 외부 사용자 관리`에서 외부/수행사 계정 목록, 접속 기간, 역할, 서비스 조회 및 등록/수정/잠금 버튼 제공
- **권한 관리**: `관리자 콘솔 > 권한 / 역할 관리`에서 역할 상세/권한 매트릭스/그룹/사용자-그룹 매핑/프로젝트 역할/서비스 권한/데이터 등급/승인 권한/조직 변경 인계/권한 변경 이력 표시
- **로그인 정책 관리**: `관리자 콘솔 > 로그인 정책`에서 정책 목록/상세, 로그인 실패 차단, 중복 로그인, 자동 로그아웃/세션 정책 표시
- **비밀번호 정책 관리**: `관리자 콘솔 > 비밀번호 정책`에서 정책 목록/상세, 복잡도, 만료/계정 잠금 현황, 계정 잠금 정책 표시
- **이력/감사로그 관리**: `관리자 콘솔 > 감사 로그`에서 대시보드, 통합 감사로그, 로그인/로그아웃/비밀번호 변경/사용자 접근/정보수정/보안 감사/관리자 조치 이력 표시
- **메뉴/프로그램 관리**: `관리자 콘솔 > 메뉴 관리`에서 트리 구조 메뉴, 상세/이동/기능 연결, 메뉴 권한 연결, 프로그램 등록 화면 표시
- **서비스 카탈로그**: `서비스/도구 카탈로그`에서 분석/개발/데이터/시각화/라벨링 도구 목록/상세/선택, 직접 입력 요청, 요구사항 대응 현황 제공
- **제안 게시판**: `제안 게시판`에서 AI 모델 개발/빅데이터 분석/데이터셋 구축 제안 목록/상세/등록, 공감/추천/댓글, 관리자 검토/공지 승인 제공
- **통합검색**: `통합검색`에서 OpenSearch `portal-catalog` 연동 검색, 필터/상세 제공
- **반출/반입 관리**: `반입·반출 승인`에서 신청/상세/등록, 상태/보안등급/감사로그 표시
- **프로젝트/워크스페이스 관리**: `프로젝트/워크스페이스`에서 목록/상세/생성 신청, 참여자/리소스 표시
- **크레딧 관리**: `크레딧 관리`에서 잔여/사용/충전 내역, 경고, 자원 단가 표시
- **마이페이지**: `마이페이지`에서 프로필/이메일/비밀번호/세션/프로젝트/자원/크레딧/알림/API Key/활동 로그 조회 및 mock 수정
- **환경설정**: `환경설정`에서 시스템 파라미터/보안 정책/자원할당 기준/운영 설정/변경 이력 조회 및 mock 수정
- **육해공군 멀티테넌트**: `육해공군 관리`에서 국방부/육군/해군/공군 테넌트 개요, 위임관리 체계, 리소스 풀, 쿼터 관리, 사용량 대시보드, 프로젝트 사용량, 경계/분리 정책, 변경 이력 조회 및 mock 관리

## 후속 단계

- **15단계**: 권한/역할/메뉴 관리 화면 상세화 (완료)
- **16단계**: 로그인/비밀번호 정책 및 감사로그 상세화 (완료)
- **17단계**: 서비스 카탈로그/제안 게시판 화면 추가 (완료)
- **18단계**: 마이페이지 및 환경설정 화면 추가 (완료)
- **19단계**: 육해공군 관리자 권한 및 멀티테넌트 관리 화면 추가 (완료)
- **20단계**: 최종 요구사항 추적표 및 제안서용 화면 정리 (완료)
- **21단계**: 제안서 작성 자료 패키징 및 화면 캡처 보강
