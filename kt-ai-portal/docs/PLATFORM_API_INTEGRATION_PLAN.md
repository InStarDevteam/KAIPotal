# 플랫폼 API 연계 설계 계획

> 보안등급: 낮음(낮)

## 개요

`플랫폼 API 연계현황` 메뉴는 포털이 **데이터 플랫폼, AI 플랫폼, 지능형 클라우드/CMP, 인증/권한, 보안/K-RMF** 등 외부 플랫폼과 연계하기 위해 필요한 API/이벤트/파일 연계 후보를 체계적으로 정리한 관리자 전용 화면입니다.

- **경로**: `/platform-api-integration`
- **접근 권한**: `visibleTo: 'admin'` + `AdminOnlyGuard`
- **데이터 기준**: PoC 단계 설계안(실제 구현 완료 API가 아님)

## 포털의 연계 역할

국방지능형플랫폼포털은 각 플랫폼을 **대체하지 않고** 다음과 같은 진입점/오케스트레이션 역할을 수행합니다.

- 단일 접점(SSO/권한 통제)
- 서비스/도구 카탈로그 및 신청
- 프로젝트/워크스페이스 생성 요청
- 반입·반출 승인 workflow
- 크레딧/자원 사용량 조회
- K-RMF 증빙/감사 이력 연계

## 연계 상태 정의

| 상태 | 의미 |
|------|------|
| `PoC Mock` | PoC 화면에서 mock 데이터 또는 단순 proxy로 시연 중 |
| `설계필요` | 연계 대상/명세/보안 정책 확정이 필요 |
| `후속연동` | 설계 후 실제 연동 개발 예정 |
| `연동대상확인필요` | 연계가 필요한지 또는 어떤 시스템과 연계할지 확인 필요 |
| `부분구현` | 일부 스펙은 구현/검증되었으나 완전 연동은 아님 |

## 공통 보안 고려사항

- **인증**: 모든 백엔드 연계는 JWT/ID token 기반, Keycloak/Firebase Auth 중 선택
- **권한**: role claim 또는 scope 기반 접근 통제, 테넌트 격리
- **전송**: TLS 1.2 이상, 민감 데이터 암호화
- **파일**: DLP 스캔, 바이러스 검사, 전송 무결성 검증
- **감사**: 사용자 행위 및 연계 호출 이력 수집

## 후속 단계

1. 각 플랫폼 담당 팀과 실제 API 명세(endpoint, request/response, 인증 방식) 확정
2. 연계 우선순위 산정(핵심 workflow: 인증, 프로젝트, 반입·반출, 검색)
3. 상세 인터페이스 정의서 작성 및 보안 검토
4. PoC Mock → 실제 연계로 전환(개발/통합/성능/보안 테스트)

## CSV 다운로드

화면 상단 `CSV 다운로드` 버튼으로 전체 연계 후보 목록을 CSV로 추출할 수 있습니다.


## 31단계 연계

- `업무흐름/연계 시나리오`(`/workflow-scenarios`)에서 각 API/연계 후보가 어떤 사용자 흐름의 어떤 단계에서 사용되는지 확인할 수 있습니다.
- API 연계 설계안은 시나리오 단계의 `relatedApiIds`와 연결되어 제안/사업관리자가 맥락을 파악할 수 있습니다.
