## 매핑 요약

- **총 19개 화면**을 RFP 기능번호와 매핑 (관리자 전용 요구사항 진도표 포함)
- **1~163 전체 기능군**에 대응하는 화면 존재
- **내부 로직은 대부분 Mock**이며 실제 연동은 후속 개발 대상

## 27단계 반영사항

- 기능번호 1~155 → 1~163 확장
- 신규 8개 기능은 기존 화면(Integrated Search, Project Workspace, Credit Manager, Export Approval) 및 후속 개발 영역에 매핑
- SFR-012, SFR-016, SFR-017 범위가 신규 기능으로 확대됨


## 28단계 반영사항

- 왼쪽 메뉴를 RFP/SFR 흐름에 맞게 재정렬
- 메뉴 그룹: 포털 공통, 관리/보안, 플랫폼 연계, 프로젝트 운영, 사용자/조직, 사용자 지원
- 기존 라우트 URL과 컴포넌트 파일명은 유지
- 각 메뉴 Tooltip에 관련 SFR 표시 (관리자 전용 제어는 29단계 예정)
- 상세 메뉴 정의는 `docs/MENU_FUNCTION_RELATIONSHIP_GUIDE.md` 참조
