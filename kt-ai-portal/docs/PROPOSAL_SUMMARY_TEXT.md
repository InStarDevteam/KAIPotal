# 제안서 작성용 요약 문구

> 아래 문구는 제안서 각 장에 바로 붙여넣을 수 있도록 작성한 완성형 문단입니다.  
> 화면 캡처와 함께 사용하면 시연 가능성을 높일 수 있습니다.

## 1. 포털 개요 문구

국방지능형플랫폼포털(K-Defense Intelligence Platform)은 국방 AI 데이터·모델·프로젝트·도구·크레딧을 하나의 포털에서 통합 관리하는 AI 데이터 운영 플랫폼입니다. Backstage 기반의 확장 가능한 포털 구조와 Keycloak OIDC 인증, OpenSearch 통합검색, OpenMetadata 데이터 거버넌스를 핵심으로 하며, 육해공군별 멀티테넌트 관리와 반입/반출 승인, K-RMF 증빙 관리 등 국방 특화 요구사항을 반영하였습니다. Portal Dashboard에서는 데이터셋·AI 모델·프로젝트·크레딧·K-RMF 진행률·시스템 상태를 한 눈에 확인할 수 있으며, 주요 메뉴로 즉시 이동할 수 있는 Quick Links를 제공합니다.

## 2. 통합 대시보드 설명 문구

Portal Dashboard는 플랫폼 전체 현황을 요약 카드와 위젯 형태로 제공합니다. 등록 데이터셋 수, AI 모델 수, 진행 중 프로젝트 수, 반출/반입 대기 건수, 크레딧 잔액, K-RMF 증빙 진행률, OpenSearch/OpenMetadata 시스템 상태, 군별 프로젝트/쿼터 변경/과다 사용 경고 등 주요 지표를 실시간으로 확인할 수 있습니다. 또한 공지사항, 최신 등록 자산, 내 프로젝트, 반출/반입 대기 현황을 동일 화면에서 제공하여 관리자와 연구자 모두가 필요한 정보를 빠르게 파악할 수 있습니다.

## 3. 통합검색/카탈로그 설명 문구

Integrated Search는 OpenSearch를 기반으로 데이터셋·AI 모델·Docker 이미지·PyPI 패키지·문서를 통합 검색합니다. 보안등급(공개/내부/비밀), 유형, 소유자, 태그 등 다양한 필터를 제공하며, 검색 결과에서 메타데이터 상세 정보와 OpenMetadata catalog로 연결할 수 있습니다. OpenMetadata 연동을 통해 데이터 계보, 태그, 용어집 기반의 거버넌스를 지원하며, 후속 단계에서는 임베딩 기반 유사도 검색과 권한 기반 필터 enforcement를 추가할 예정입니다.

## 4. 프로젝트/워크스페이스 설명 문구

Project Workspace는 AI 연구/개발 프로젝트의 전체 생애주기를 관리하는 화면입니다. 프로젝트 등록, 멤버 초대, 워크스페이스 자원 요청, GPU/CPU/스토리지 사용량 모니터링, 프로젝트별 크레딧 현황을 한 곳에서 조회할 수 있습니다. 템플릿 기반 프로젝트 생성과 승인 workflow를 지원하며, 후속 연동을 통해 Kubernetes namespace, 리소스 quota, CMP 자원 풀과 연결하여 실제 워크스페이스를 자동 프로비저닝할 수 있습니다.

## 5. 반입/반출 관리 설명 문구

Export Approval은 데이터 반입/반출에 대한 신청·승인·보안 검토 workflow를 지원합니다. 사용자는 반출 대상 데이터, 목적, 보안 등급, 필요 권한을 입력하여 신청하고, 승인자는 보안 검토 후 승인/반려할 수 있습니다. 반출/반입 이력과 상태를 추적할 수 있으며, Admin Console의 승인 권한 설정 및 감사 로그와 연계하여 책임 소재를 명확히 관리합니다. 후속 개발에서는 파일 저장소 연동, DLP/마스킹 검토, 반출물 만료 회수 기능을 추가할 예정입니다.

## 6. 크레딧 관리 설명 문구

Credit Manager는 프로젝트별 크레딧 할당과 GPU/CPU/스토리지 사용량을 관리하는 화면입니다. 전체 크레딧 잔액, 프로젝트별 사용량, 부족/과다 사용 경고, 충전/할당 내역을 시각화하여 제공하며, 크레딧 부족 시 자원 사용 제한 정책을 설정할 수 있습니다. My Page에서 개인의 크레딧 사용 내역과 자원 사용 이력을 조회할 수 있어 사용자별 비용 투명성을 확보합니다. 후속 연동에서는 실제 자원 사용량 수집, 환산 로직, 충전 workflow를 구현합니다.

## 7. 사용자/권한/RBAC 설명 문구

Admin Console의 사용자 관리 메뉴에서는 사용자 등록 신청·승인·반려, 사용자/외부 사용자 목록 및 상세 관리, 조직/부서 관리를 수행할 수 있습니다. 권한/RBAC 메뉴에서는 역할·그룹·권한 매트릭스를 통해 메뉴·데이터·서비스·프로젝트·승인 권한을 세밀하게 설정할 수 있으며, Keycloak group/role과 연동하여 실제 인프라에 반영할 수 있습니다. 조직 변경 시 권한 회수/인계 이력도 감사 로그로 관리합니다.

## 8. 정책/감사로그 설명 문구

Admin Console에서는 로그인 정책(세션 타임아웃, 동시 세션, 계정 잠금), 비밀번호 정책(복잡성, 만료, 재사용 제한), 그리고 감사 로그를 관리합니다. 감사 로그에서는 관리자 조치 이력, 사용자 활동 이력, 로그인/로그아웃 이력, 권한 변경 이력, 설정 변경 이력을 조회할 수 있어 보안 및 컴플라이언스 요구사항을 충족합니다. 후속 개발에서는 중앙 로그 수집 및 보안 이벤트 탐지 기능을 강화합니다.

## 9. 서비스/도구 카탈로그 설명 문구

Service Catalog는 AI 개발에 필요한 분석 프레임워크, 개발 도구, 데이터 도구, 시각화 도구, 라벨링 도구를 카탈로그 형태로 제공합니다. 사용자는 필요한 도구를 검색·선택·요청할 수 있으며, 카탈로그에 없는 도구는 직접 입력하여 요청할 수 있습니다. OpenMetadata 및 Docker Registry/PyPI Mirror와 연동하여 도구의 메타데이터와 설치 이미지를 관리하며, Tool approval workflow를 통해 보안 검토 후 제공합니다.

## 10. 제안 게시판 설명 문구

Proposal Board는 AI 데이터/도구/정책에 대한 아이디어를 등록·공유·승인하는 협업 공간입니다. 사용자는 제안의 필요성과 활용 가능성을 기술하고 다른 사용자의 공감과 댓글을 받을 수 있으며, 관리자는 우수 제안을 승인·공지할 수 있습니다. 제안 게시판을 통해 현장의 수요를 빠르게 수렴하고 플랫폼 개선 방향을 도출할 수 있습니다. 후속 개발에서는 알림, 첨부파일, 승인 workflow를 추가할 예정입니다.

## 11. 마이페이지/환경설정 설명 문구

My Page에서는 사용자가 프로필, 비밀번호, 활성 세션, 내 프로젝트/워크스페이스, 자원 사용 이력, 크레딧 사용 내역, 알림 수신 설정, API Key, 내 활동 로그를 관리할 수 있습니다. Environment Settings에서는 시스템 파라미터, 보안 정책, 자원할당 기준, 운영 설정과 변경 이력을 관리할 수 있어 플랫폼 운영의 일관성과 추적성을 확보합니다.

## 12. 육해공군 멀티테넌트 관리 설명 문구

Tenant Management는 육해공군 및 국방부 공통 테넌트를 통합 관리하는 화면입니다. 군별 테넌트 개요, 위임관리 체계, 군별 리소스 풀, 군별 쿼터 관리, 사용량 대시보드, 군별 프로젝트 사용량, 테넌트 경계/분리 정책, 쿼터 변경 이력, 요구사항 대응 현황을 제공합니다. 후속 연동을 통해 Kubernetes namespace, OpenStack quota, CMP 자원 풀, Keycloak group/role과 연결하여 군별 자원 분리와 권한 위임을 실제 인프라에 적용할 수 있습니다.

## 13. PoC 한계 및 후속 확장 문구

현재 구현된 화면은 Backstage 기반 포털 UI와 mock 데이터 기반 상태 전환을 중심으로 하며, 주요 업무 로직과 외부 시스템 연동은 PoC 범위에 포함되지 않았습니다. 실제 Keycloak Admin/Event API, DB/API, Kubernetes/OpenStack/CMP, 파일 저장소, OpenMetadata/OpenSearch 자동 동기화, 크레딧 차감/자원 제한 enforcement 등은 20단계 이후 후속 개발 과제로 정리되어 있습니다. 본 PoC는 제안서 및 시연용 화면 정리를 목적으로 하며, 실제 운영 전 보안 검토와 연동 구현이 추가로 필요합니다.
