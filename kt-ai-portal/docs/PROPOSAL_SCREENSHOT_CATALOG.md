## 추가 캡처 권장 사항

- **관리자 콘솔 요약 카드 확대 캡처**: 등록 신청 대기/승인 대기/외부 사용자/활성 사용자 수치를 강조할 때 유용합니다.
- **육해공군 관리 요약 카드 확대 캡처**: 군별 프로젝트 수, GPU 할당/사용량, 쿼터 변경 대기, 과다 사용 경고를 강조할 때 유용합니다.
- **서비스/도구 카탈로그 도구 상세 화면**: 특정 도구(Jupyter, Label Studio 등) 선택/요청 흐름을 보여줄 때 유용합니다.
- **크레딧 관리 사용량 차트**: GPU/CPU 사용량 시각화를 강조할 때 유용합니다.
- **Sidebar 전체 메뉴 강조 캡처**: 한글 메뉴를 보여주는 데 유용합니다.

## 35단계 활용 반영

- 권한체계 개편(역할 7종·권한 22종)과 최종공고 실구현(K-RMF 8탭, 작업환경 Wizard, 실증·데이터 준비)을 반영하여 전체 캡처를 production URL에서 재촬영.
- 역할 기반 신규 캡처 10종 추가: 사용자/관리자 대시보드·메뉴, 권한별 메뉴 비교, K-RMF 대시보드·통제증적·평가인가·운영전환, 실증 데이터 준비.
- 레거시 캡처는 파일명을 유지하고 촬영 역할을 새 권한 모델에 맞게 조정(K-RMF는 krmf-manager, 환경설정/육해공군 관리는 portal-admin).
- 캡처 검증은 DOM 기준 4종 게이트(portal-shell, data-capture-id, 금지 텍스트 부재, 해시 중복 검사)를 통과한 결과만 저장.
