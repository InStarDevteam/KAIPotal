# 데모 시나리오 (Demo Script)

> 국방지능형플랫폼포털(K-Defense Intelligence Platform) 제안 발표 및 시연용 시나리오입니다.  
> 각 화면은 `docs/assets/final/`의 캡처 파일과 함께 설명할 수 있습니다.

## 1. Keycloak Login

- **시연 목적**: OIDC 기반 통합 인증과 보안 정책을 보여줍니다.
- **클릭 경로**: Backstage Sign-In → Keycloak 로그인
- **강조할 요구사항**: 9~12, 45~55 (로그인/비밀번호/세션 정책)
- **설명 멘트**: "Backstage의 통합 로그인 포털에서 Keycloak OIDC를 통해 인증합니다. 게스트 로그인도 지원하며, 비밀번호 정책과 세션 정책은 Keycloak에서 중앙 관리됩니다."
- **주의사항**: 실제 Keycloak realm이 미리 구성되어 있어야 합니다.

## 2. Portal Dashboard

- **시연 목적**: 플랫폼 전체 현황을 한 눈에 보여줍니다.
- **클릭 경로**: `/` Home
- **강조할 요구사항**: 1~8 (메인 포털)
- **설명 멘트**: "로그인 후 Portal Dashboard에서 데이터셋, AI 모델, 진행 중 프로젝트, 반출/반입 대기, 크레딧 잔액, K-RMF 진행률, 시스템 상태, 군별 프로젝트/쿼터/과다 사용 경고를 확인할 수 있습니다."
- **주의사항**: 요약 지표는 mock 데이터이므로 수치가 고정되어 있습니다.

## 3. 통합검색

- **시연 목적**: OpenSearch 기반 통합검색 기능을 보여줍니다.
- **클릭 경로**: `/integrated-search`
- **강조할 요구사항**: 63~72 (통합검색)
- **설명 멘트**: "데이터셋·AI 모델·Docker 이미지·PyPI 패키지·문서를 보안등급과 유형으로 필터링하여 검색할 수 있습니다. OpenSearch proxy를 통해 실제 인덱스를 조회합니다."
- **주의사항**: OpenSearch 컨테이너가 실행 중이어야 합니다.

## 4. 프로젝트/워크스페이스

- **클릭 경로**: `/project-workspace`
- **강조할 요구사항**: 80~96 (프로젝트/워크스페이스)
- **설명 멘트**: "AI 연구 프로젝트를 등록하고 멤버·워크스페이스·자원 사용량을 관리할 수 있습니다. 템플릿 기반 생성과 승인 workflow를 지원합니다."
- **주의사항**: 실제 워크스페이스 생성은 아직 연동되지 않았습니다.

## 5. 반입·반출 승인

## 8. 관리자 콘솔

### 8.1 사용자 관리

- **시연 목적**: 사용자 등록/승인/외부 사용자 관리를 보여줍니다.
- **클릭 경로**: `/admin-console` → 사용자 등록 신청 / 사용자 관리 / 외부 사용자 관리
- **강조할 요구사항**: 21~35 (사용자/외부 사용자)
- **설명 멘트**: "관리자는 사용자 등록 신청을 승인/반려하고, 사용자와 외부 사용자를 조직/역할 중심으로 관리할 수 있습니다."
- **주의사항**: 본인인증 및 Keycloak 연동은 미구현입니다.

### 8.2 권한/RBAC

- **시연 목적**: 역할·그룹·권한 매트릭스를 보여줍니다.
- **클릭 경로**: `/admin-console` → 권한 / 역할
- **강조할 요구사항**: 36~44, 56~62 (권한/RBAC/메뉴)
- **설명 멘트**: "역할·그룹·메뉴·데이터·서비스·프로젝트·승인 권한을 세밀하게 설정하고 변경 이력을 추적할 수 있습니다."
- **주의사항**: Keycloak role/group 연동은 후속 개발입니다.

### 8.3 로그인/비밀번호 정책 및 감사 로그

- **시연 목적**: 보안 정책과 감사 이력을 보여줍니다.
- **클릭 경로**: `/admin-console` → 로그인 정책 / 비밀번호 정책 / 감사 로그
- **강조할 요구사항**: 9~20, 45~55, 135~142 (정책/감사)
- **설명 멘트**: "로그인·비밀번호·세션 정책을 설정하고 관리자/사용자 행위를 감사 로그로 남깁니다."
- **주의사항**: 정책 enforcement는 mock 상태입니다.
