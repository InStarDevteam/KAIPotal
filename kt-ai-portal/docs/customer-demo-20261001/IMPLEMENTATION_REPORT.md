프로필 입력으로 테넌트·역할·사용자 신원이 바뀌지 않는다. 외부 사용자로 변경하면 군번 등 군 내부 필드는 지워진다. 초기 로컬 수정 단계에서는 운영 DB에 테스트 프로필이나 프로젝트를 넣지 않았다. 이후 사용자의 후속 구현·배포 승인에 따라 운영 DB에 합성 일반 프로젝트 **`[시연] 군수 데이터 분석` 1개와 작업환경 요청 1개**를 등록하고 승인까지 검증했다. 공개 URL 재검증은 기존 항목을 재사용했다. 프로필 저장 검사는 기존 값을 복구했으며, 외부 플랫폼 자원이나 별도 실증 관리 기능을 생성하지 않았다. 생성 항목과 검증 결과는 [공개 사이트 API 기록](deployment/live-api/backend-verification.json)에 있다.

환경설정 변경 이력도 이번 후속 작업에서 실제 서버 원장으로 연결했다. 변경자·시각·전후 값과 분류·페이지 탐색을 제공하고, 현재 값과 이력의 민감 설정은 서버 응답에서 숨긴다. 전체 단위 테스트 422개와 PostgreSQL 132개 검사 결과는 [VALIDATION.md](VALIDATION.md)를 따른다.

## 권한별 포털 업무 첫 화면

상단 ‘포털 업무’와 홈 진입 버튼은 중간 팝업 없이 실제 유효 권한에 맞는 화면으로 이동한다. 복수 권한의 우선순위는 포털 운영 → 테넌트 운영 → 보안 검토 → 프로젝트 운영 → 감사 조회 → 나의 업무다. 화면 종류를 바꾸는 것이 서버 권한을 부여하지 않는다.

| 사용자층 | 첫 화면 | 우선 정보 | 대표 작업 |
|---|---|---|---|
| 일반 사용자 | 나의 업무 | 참여 프로젝트, 본인 신청 현황, 허용 플랫폼 | 작업환경 신청·프로젝트 상세 |
| 프로젝트 관리자 | 프로젝트 운영 | 관리 프로젝트, 검토할 작업환경 신청 | 작업환경 신청·승인·반려 |
| 군별 관리자 | 테넌트 운영 | 소속의 승인 업무, 플랫폼 접근, 연결된 자원 상태 | 사용자·접근 관리 |
| 포털 관리자/슈퍼유저 권한 계정 | 포털 운영 | 선택한 소속의 승인 업무, 플랫폼 연결, 운영 현황 | 테넌트 관리·관리자 위임 |
| 보안 담당자 | 보안 검토 | 반입·반출 검토 대상, 접속·사용 이력 | 반입·반출 검토 |
| 보안 감사관 | 감사 조회 | 감사·변경 기록, 읽기 전용 현황 | 감사 이력 조회 |

GPU·서버 계량은 CMP에서 아직 제공되지 않으면 연결 대기로 표시한다. 작업환경 승인 완료는 포털 원장 상태이며, 외부 플랫폼의 자원 생성 완료를 의미하지 않는다.

## 남아 있는 실제 연결 범위

기관 IdP의 다른 기기 세션 조회·종료, 이메일 인증·비밀번호 변경, 개인 API 키·알림 전송, CMP 사용량·쿼터 수집, 각 플랫폼 작업환경 프로비저닝은 이번에 새로 연결 완료했다고 설명하지 않는다. 관련 기능 메뉴는 보존하고 연결 상태를 표시한다. 외부 플랫폼의 계약과 테스트 자격 증명이 있어야 후속 검증할 수 있다.

운영 협의 계정의 실제 등록 소속은 국방부 공통 1개다. 5개 소속 전환은 권한이 등록된 로컬 테스트 계정으로 검증했다. 운영 계정에 소속을 임의로 추가하지 않았다.
