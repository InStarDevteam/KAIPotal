## 이번 개선

- 업무 첫 화면의 본인 신청과 검토 대기에 별도 크레딧·반입반출 원장이 빠지던 문제를 수정했다. 실제 총건수와 최근 10건, 현재 소속·본인·검토 권한을 함께 검사한다. 기존 신청 원장을 복제하거나 업무 상태를 바꾸지 않는다.
- 통합검색은 입력 전·실제 0건·검증 오류·원천 연결 실패를 구분한다. 원천 조회 실패는 별도로 재시도할 수 있다. 미연결 원천도 데이터셋·모델 등 이름으로 구분한다.
- 검색어·종류·페이지를 URL로 유지해 같은 화면의 상단 재검색, 브라우저 뒤로 가기, 새로고침을 복원한다. 서버 페이지 요청으로 50건 이후 결과도 조회한다.
- 이전 검색/소속의 늦은 응답과 자동완성 결과를 제외하고 입력 지연을 적용했다. 검색 입력/실행의 한국어 라벨, 모바일 긴 제목, 내부 상세 이동을 보완했다.
- 주요 검색·설정·감사·크레딧·반입반출 시각에 한국 시간 표시를 적용했다. 원본 API 날짜 값과 업무 상태 코드는 바꾸지 않았다. 지원 문의용 request ID를 보존한다.
- K-RMF 파일 저장소 미설정 시 컨테이너 내부 기본 디렉터리에 저장하던 동작을 교정했다. 명시적 저장소가 없으면 파일 업로드/다운로드는 `storage_unavailable` 503, 조회는 연결 상태, UI는 파일 선택 제어와 참조 URI 안내를 제공한다. 참조 URI 등록과 기존 명시적 파일 경로는 유지한다.

새 플랫폼 엔진이나 기관 인증을 임의로 추가하지 않았다. 홈 4종, 기존 메뉴·기능과 현재 서버 인가를 유지한다. 이번 변경에는 DB migration이나 운영 원장 쓰기 검증/추가 샘플 등록이 없다.
