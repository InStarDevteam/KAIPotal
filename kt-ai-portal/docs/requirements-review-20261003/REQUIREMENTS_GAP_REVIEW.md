# 요구사항·UI/UX 미비사항 및 팀 협의안 — 2026-10-03

이 검토는 현재 포털 코드, 10월 1일 배포 증적, 10월 3일 실제 API 읽기 점검을 기준으로 한다. 외부 팀과의 합의는 아직 없으며 아래 담당 팀은 **담당 역할의 제안**이다. 실제 담당자·승인자·기한은 첫 협의에서 지정한다. 이번 수정과 최종 배포 결과는 [RELEASE_REPORT.md](RELEASE_REPORT.md)에 기록한다.

## 판단 기준

- 원문 기준선: `요구사항/01. (ICTWAY) 견적서(안)_국방 지능형 플랫폼 고도화 구축사업_견적(안)_260812_v1.0.pdf`의 FP 531행과 동일 추출 CSV. 이는 견적용 기능 목록이며 최종 RFP 전문과 동일한 문서라고 단정하지 않는다.
- 요구영역: 저장소의 `FINAL_RFP_PORTAL_BOUNDARY_REVIEW.md`에 정리된 SFR-001~021, 제안서 및 최신 고객 지시. RFP 전문·승인된 변경 기준선은 사업관리팀과 확정한다.
- 포털은 공통 진입·권한·조회·신청·승인·이력을 맡고 상세 작업은 각 플랫폼에서 한다. 홈에는 4개 플랫폼 진입을 중심으로 유지한다. 대시보드 요구를 이유로 홈에 많은 위젯을 추가하지 않는다.
- 실증은 이 체계를 이용하는 활동이다. 별도 실증 관리 프로그램이나 추정 API를 복원하지 않는다.
- 원장 저장, 실제 인증, 외부 서비스 실행, 기관 검수는 서로 다른 완료 조건이다. 09-30의 완료율을 현재 완료율로 재사용하지 않는다. 이번 엑셀의 531행 연결은 추적용이며 각 FP의 요구 전체 충족 판정을 다시 완료했다는 뜻이 아니다.

## 종합 판단

프로젝트·신청·승인·크레딧·반입반출·제안·설정·감사의 포털 원장은 구현되어 있지만, 기관 인증과 외부 플랫폼 실행은 아직 미연결이다. 개발 관리자에 있는 8개 대상도 실제 API에서 모두 `configured=false`다. 외부 엔진의 미연결과 포털 어댑터·작업자·오류 복구의 미구현을 모두 관리해야 한다. 주소만 받으면 모든 기능이 자동으로 완료되는 상태가 아니다.

업무 집계가 작업환경 원장만 읽고 별도 크레딧·반입반출 신청을 누락하던 부분도 확인해, 본인 신청과 실제 검토 권한에 맞게 기존 원장들을 함께 집계하도록 보완했다. 카탈로그는 기존 작업환경 원장 연결을 유지하며 별도 복제하지 않는다.

UI/UX는 홈 4종·권한별 업무 진입·국방 프로필·프로젝트 카드·공통 표 개선이 반영되어 있다. 이번 검토에서는 검색의 진입 상태, 같은 경로의 재검색, URL 복원, 페이지 이동, 비동기 응답 순서와 시간 표시를 직접 보완했다. 추가로 K-RMF 파일 저장소가 미설정인데도 컨테이너 내부 저장으로 진행되는 결함을 확인했다. 파일 유실을 막도록 명시적 저장소 설정을 요구하고, 화면에 상태를 안내하며 참조 URI 등록은 지원한다. **영구 파일 저장소 제공까지 완료한 것은 아니다.**

| G13 | P1 | K-RMF 공식 기준선·예외·평가/인가 연계 미정 | 기관 지정 기준판·매핑·서명/무결성·평가 책임 수령, 기준선 import·실대사 |
| G14 | P1 | RFP 변경 기준선·MDR 표준사전·검수 책임 미확정 | 사업관리·데이터표준팀이 승인본·용어/코드·등록양식 제공. 현재 내부 표준을 기관 승인으로 설명하지 않음 |
| G15 | P1 | 운영망 배치·HA·자동 백업·복구/성능 목표 미정 | 운영/인프라가 토폴로지·RTO/RPO·SLA·부하/장애 시험 조건 확정. 현재 Cloud Run 시연 배포와 별도 |

P0는 기관 실운영 전 반드시 해결할 항목이다. 이는 현재 협의용 사이트를 전면 중단한다는 뜻이 아니라, 현재 사용 범위와 운영 전환 조건을 구분한 우선순위다.

## 협의 진행 순서

1. 사업관리자가 승인 요구 기준선과 각 팀의 인터페이스 담당자·승인자를 지정한다. 미비 목록의 담당자·기한·결정 근거를 채운다.
2. 인증/조직/권한과 공통 연결 키를 먼저 합의한다. 다른 팀은 이 식별자를 동일하게 사용한다.
3. AI·데이터·CMP·VDI의 최소 성공/실패 흐름, 파일 저장/검사/전송, 사용량/정산을 각각 합의한다.
4. 포털 어댑터·outbox 작업자·사용자 상태 안내를 구현하고 계약 시험을 수행한다. 합의 이전에 임의 외부 실행을 하지 않는다.
5. 실제 기관 계정으로 6개 사용자층의 로그인→업무→플랫폼 상세 작업→회수 흐름과 망/장애/복구 시험을 완료한다.

이번에는 협의 의제와 추적 산출물을 준비했으며, 팀 연락·회의·외부 합의를 수행하지 않았다. 엑셀의 담당자/확정기한/합의여부 칸을 협의 때 직접 채울 수 있다.
