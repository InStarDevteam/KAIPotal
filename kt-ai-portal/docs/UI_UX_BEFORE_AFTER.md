# UI/UX Before / After 비교 (33.2단계)

> 캡처 위치: `docs/assets/design-stage33-2/before/`, `docs/assets/design-stage33-2/after/`
> 해상도: 1920×1080, 1440×900, 1366×768 / 대상: 대시보드, K-RMF, 통합검색, 프로젝트/워크스페이스, 크레딧 관리, 관리자 콘솔

## 1. 통합 대시보드

| 항목 | Before | After |
|---|---|---|
| 히어로 | 큰 그라디언트 블록, 정보 혼재 | 높이 30% 축소, navy 단색, 제목/설명과 사용자 정보(역할 RoleBadge·상태 칩) 좌우 분리 |
| 검색 | 입력창과 버튼 분리 | 결합형 검색 컴포넌트 |
| 지표 카드 | 14개 카드 단일 그리드 나열 | [업무 현황]/[자원 및 크레딧]/[플랫폼 현황]/[보안 및 거버넌스] 4개 섹션, Primary/Secondary 크기 차별 |
| 보안 지표 | 모든 사용자에게 노출 | `krmf.view` 권한자만(기존 게이트 유지하며 섹션 단위 적용) |
| 하단 패널 | 카드 스타일 제각각 | SectionCard 스타일 통일 |

- 비교 캡처: `before/dashboard-1920.png` ↔ `after/dashboard-1920.png` (1440/1366 동일 파일명 규칙)

## 2. K-RMF 이행·증적관리

| 항목 | Before | After |
|---|---|---|
| 단계 흐름 | 전역 8단계와 K-RMF 8단계가 비슷한 강조로 혼재 | 전역은 subdued 보조 흐름, 'K-RMF 이행 단계' 캡션+navy 액센트로 주 흐름 구분 |
| 헤더 | 제목/설명만 | PageHeader + 우측 현재 역할 RoleBadge |
| 진척률 | 텍스트 위주 요약 | 전체 진척률 navy 주요 카드 + 보조 지표 MetricCard, 미흡 warning/고위험 error |
| 영역별 진척률 | 바 높이/색상 불일치 | 6px 통일, 0% 회색/중간 blue/100% 초록 |
| 탭 | 기본 스타일 | 48px 높이, active 인디케이터 3px, sticky 탭 바 |

- 비교 캡처: `before/krmf-1920.png` ↔ `after/krmf-1920.png`

## 4. 해상도별 확인

| 해상도 | 확인 결과 |
|---|---|
| 1920×1080 | KPI 4열, 상세 8:4, 모든 섹션 정상 |
| 1440×900 | KPI 3~4열 유지, 레이아웃 파손 없음 |
| 1366×768 | 카드 줄바꿈 정상, 가로 스크롤 없음, 메뉴 전체 표시 |
