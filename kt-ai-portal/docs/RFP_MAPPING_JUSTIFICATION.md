# RFP 매핑 근거 설명

> 본 문서는 각 화면/기능이 RFP 기능번호에 왜 대응하는지 설명하는 근거 자료입니다.  
> 제안서에서 "왜 이 화면이 해당 요구사항에 부합하는지" 답변할 때 활용합니다.

## 1. 메인 포털

- **대응 기능번호**: 1~8
- **대응 화면**: `01-portal-dashboard.png`
- **매핑 근거**:
  - 포털 메인 화면은 플랫폼 전체 현황을 요약하여 제공하는 기능(1~4)에 해당합니다.
  - 데이터셋·AI 모델·프로젝트·크레딧·K-RMF·시스템 상태를 한 눈에 보여주는 요약 카드는 현황 파악(5~6)에 해당합니다.
  - 공지사항, Quick Links, 최신 등록 자산은 사용자 편의성 및 메뉴 접근성(7~8)에 해당합니다.

## 2. 로그인/인증

- **대응 기능번호**: 9~12, 45~55
- **대응 화면**: `09-backstage-signin.png`, `09-keycloak-login.png`
- **매핑 근거**:
  - Backstage Sign-In 화면은 OIDC 및 게스트 로그인 선택(9~12)을 제공합니다.
  - Keycloak Login은 OIDC 인증, 비밀번호 정책, 세션 정책, MFA(45~55)의 실제 구현체입니다.

## 3. 사용자 관리

- **대응 기능번호**: 21~35
- **대응 화면**: `07-admin-console-user-management.png`
- **매핑 근거**:
  - 사용자 등록 신청·승인·반려(21~25)
  - 사용자/외부 사용자 목록 및 상세 관리(26~30)
  - 조직/부서 관리(31~35)

## 4. 권한/RBAC

- **대응 기능번호**: 36~44, 56~62
- **대응 화면**: `08-admin-console-rbac-menu.png`
- **매핑 근거**:
  - 역할·그룹·권한 매트릭스(36~44)
  - 메뉴·데이터·서비스·프로젝트·승인 권한 설정(56~62)

## 5. 보안정책/감사로그

- **대응 기능번호**: 9~20, 45~55, 135~142
- **대응 화면**: `09-admin-console-policy-audit.png`
- **매핑 근거**:
  - 로그인 정책, 비밀번호 정책, 세션 정책(9~20, 45~55)
  - 감사 로그 조회: 관리자 조치, 사용자 활동, 권한 변경, 설정 변경(135~142)

## 6. 통합검색/카탈로그

- **대응 기능번호**: 63~79
- **대응 화면**: `02-integrated-search.png`, `15-openmetadata-catalog.png`, `16-opensearch-catalog-index.png`
- **매핑 근거**:
  - 데이터셋·AI 모델·Docker 이미지·PyPI 패키지·문서 통합 검색(63~72)
  - 보안등급·유형·소유자·태그 필터(63~72)
  - OpenMetadata를 통한 메타데이터·계보·용어집 관리(73~79)

## 7. 프로젝트/워크스페이스

## 8. 반입/반출

  - 보안 검토 및 승인/반려(101~104)

## 9. 크레딧

- **매핑 근거**:
  - 크레딧 잔액/할당/사용량(109~114)
  - 부족/과다 사용 경고, 충전/회수(115~118)

## 10. 마이페이지/환경설정

- **대응 기능번호**: 119~134

  - 시스템 파라미터, 보안 정책, 자원할당 기준, 변경 이력(131~134)

## 11. 육해공군 멀티테넌트

## 13.1 신규 기능 156~163 매핑 근거

- **플랫폼 연동 (156~158)**: 데이터 플랫폼, AI 플랫폼, 지능형 클라우드와의 API 연동 범위·메타데이터 연계를 SFR-012/플랫폼 연동에 편입. 통합검색 및 OpenMetadata 연동 화면과 연계.
- **프로젝트 관리 확장 (159~161, 163)**: 워크스페이스 접속 링크, 종료 시 산출물 저장/반출, 추가 자원 요청/승인, 학습/라벨링 작업 할당을 SFR-016/프로젝트 관리에 편입. Project Workspace 및 Export Approval 화면과 연계.
- **크레딧/사용량 관리 (162)**: 프로젝트별 크레딧 잔액·추이 대시보드를 SFR-017/크레딧 신청 및 조회에 편입. Credit Manager 화면과 연계.

## 14. 메뉴 RFP/SFR 순서 재정렬 (28단계)

- 왼쪽 메뉴 순서를 RFP/SFR 흐름에 맞춰 재정렬하였습니다.
- 기존 화면/라우트는 변경하지 않고 메뉴 표시 순서만 조정하였습니다.
- 메뉴 그룹 및 SFR 매핑은 `docs/MENU_FUNCTION_RELATIONSHIP_GUIDE.md`를 참조하세요.


## 15. 관리자 전용 요구사항 진도표 (29단계)

- **대응 기능번호**: 1~163 (전체), SFR-001~SFR-021 (전체)
- **대응 화면**: `/requirement-progress`
- **매핑 근거**:
  - 사전규격 기준 163개 기능목록과 21개 SFR의 UI 구현 현황을 한눈에 조회하는 관리자 전용 화면
  - 기능목록 1~163의 구현 상태(화면 구현, 부분 구현, 후속 개발, 검토 필요)를 집계하여 표시
  - SFR-001~SFR-021별로 관련 기능번호, 진척률, 영향도, 우선순위, 권고사항을 조회
  - 변경이력(CHG-001~CHG-013)과 질의사항 7건을 함께 관리하여 제안/사업관리 검토 지원
- **비고**:
  - 본 화면은 제안팀 검토용 PoC 데모가 아닌, 납품 후 운영/사업관리자를 위한 내부 관리 도구로 활용
  - 일반 사용자에게는 메뉴가 노출되지 않으며 직접 URL 접근도 차단됨


## 16. 관리자 전용 요구사항 대응현황 (30단계)

- **대응 기능번호**: 1~163 (전체), SFR-001~SFR-021 (전체)
- **대응 화면**: `/requirement-coverage` (기존 `/requirement-progress` 별칭)
- **매핑 근거**:
  - 사전규격 기준 163개 기능목록과 21개 SFR의 UI 구현 현황을 메뉴, SFR, 기능 단위로 체계적으로 조회
  - 각 메뉴가 어떤 SFR을 대응하고, 어떤 기능이 화면구현/부분구현/후속개발 상태인지 추적
  - 변경이력과 질의사항을 함께 관리하여 제안/사업관리 검토 지원
- **비고**:
  - 본 화면은 제안팀 검토용 PoC 데모가 아닌, 납품 후 운영/사업관리자를 위한 납품 후 관리 도구
  - `visibleTo: 'admin'` + `AdminOnlyGuard`로 일반 사용자 접근 차단

## 17. 플랫폼 API 연계현황 (30단계)

- **대응 기능번호**: 156~163 (플랫폼 연동, 신규 기능), 80~96, 110~118, 150~155 (프로젝트/크레딧/테넌트)
- **대응 화면**: `/platform-api-integration`
- **매핑 근거**:
  - SFR-012 "플랫폼 연동"의 구체적 연계 후보를 포털-데이터/AI/클리우드/인증/보안 플랫폼 단위로 정의
  - SFR-014/015 카탈로그/검색, SFR-016/017/018 프로젝트/크레딧/워크스페이스, SFR-021 육해공군 권한 위임과 관련된 API/이벤트/파일 연계 후보를 목록화
  - PoC 기준 설계안으로, 실제 연동 개발 전 인터페이스 정의서 및 보안 검토의 기초 자료로 활용
- **비고**:
  - 20개 연계 후보는 실제 구현 완료 API가 아님
  - CSV 다운로드를 통해 연계 설계안 공유 및 검토 가능


## 18. 업무흐름/연계 시나리오 (31단계)

- **대응 기능번호**: 1~163 전반(프로젝트/검색/카탈로그/반출/크레딧/테넌트 등)
- **대응 화면**: `/workflow-scenarios`
- **매핑 근거**:
  - SFR-001 통합 포털 접점, SFR-012 플랫폼 연동, SFR-014/015 카탈로그/검색, SFR-016/017/018 프로젝트/크레딧/워크스페이스, SFR-021 육해공군 관리 등의 요구사항을 사용자/플랫폼 관점 업무흐름으로 재구성
  - 각 시나리오는 단계별 수행 주체, 사용 메뉴, 연계 플랫폼, 교환 데이터, 관련 API, RFP 근거를 포함
  - 평가자와 제안팀이 "포털이 왜 필요한지", "어떤 플랫폼과 연결되는지"를 즉시 이해할 수 있도록 지원
- **비고**:
