# 포털 디자인 개선 — 2026-10-11

프로젝트에 제공된 `(국방지능형) 디자인 예시.zip`의 12개 화면을 참고했다. 참고 이미지의 입체 조형, 명확한 타이포그래피, 충분한 여백, 일관된 플랫폼 카드와 업무 패널을 실제 포털 컴포넌트로 구현했다. 화면을 이미지로 붙이지 않고, 모든 입력·조회·저장·이동 기능을 유지했다.

## 4개 시안

| 시안 | 메인 표현 | 업무 화면의 표현 | 동일하게 유지하는 기능 |
| --- | --- | --- | --- |
| Aurora | 밝은 청백색, 유리 방패와 연결 구체 | 푸른 헤더, 밝고 정돈된 읽기 영역 | 4개 플랫폼, 역할별 업무 진입, 앱 메뉴, 개인 바로가기 |
| Focus | 깊은 청록색, 은빛 방패 | 청록 헤더, 차분한 중성색 패널 | 위와 동일 |
| Orbit | 흑연색과 금색, 금속 궤도 | 흑연 헤더, 따뜻한 중성색 패널 | 위와 동일 |
| Canvas | 따뜻한 아이보리, 접힌 입체 조형 | 밝은 헤더, 아이보리 읽기 영역 | 위와 동일 |

업무 화면은 정보의 가독성을 위해 4개 시안 모두 밝은 읽기 영역을 사용한다. 헤더·내비게이션·강조색·표·카드·입력 폼·팝업·타이포그래피는 공통 테마를 따른다. AI·데이터·클라우드·VDI 아이콘은 동일한 입체 SVG 계열이며, 업무 메뉴는 일관된 선형 아이콘을 사용한다.

## 군별 설정과 개인 설정

- 군 관리자: **군별 포털 설정 → 테마와 공통 문구**에서 기본 시안, 대표·강조 색상, 로고, 포털 문구, 글자 크기(90/100/110/120%)를 저장한다. 기존 메뉴 이름·노출·순서 및 플랫폼 접근 설정을 유지한다.
- 사용자: **내 계정 → 화면 디자인과 글자 크기** 또는 **마이페이지 → 화면 설정**에서 군 기본값을 상속하거나 개인 시안·크기를 저장한다. 현재 계정과 소속 군을 기준으로 저장한다.
- 적용 순서: 고객 협의용 임시 시안 선택 → 저장한 개인 디자인 → 군 기본 디자인. 개인 글자 크기를 지정하지 않으면 군 기본 크기를 사용한다.
- 관리자 또는 사용자가 디자인을 저장하면 임시 선택을 해제하고 저장한 설정을 즉시 적용한다. 하단 4개 버튼으로 다시 시안을 비교할 수 있다.
- 협의용 버튼은 기존 `app.designReviewEnabled` 설정으로 표시를 제어한다. 표시를 끄더라도 저장한 군·개인 디자인은 계속 적용된다.

기존 PostgreSQL의 군 설정 JSONB와 개인 설정 JSONB를 사용한다. 테이블 신설이나 샘플 초기화 없이 기존 설정을 호환하며, 이전 클라이언트의 저장 요청도 새 디자인 설정을 보존한다. 군 설정 변경 권한·버전 충돌 검사·감사 기록을 유지한다.

## 로그인과 사용성

Google 로그인 버튼, OAuth 클라이언트 및 별도 Firebase 인증 리스너를 제거했다. 현재 고객 협의 환경의 접근코드 로그인과 실제 BFF 세션을 유지하고, 기관 OIDC 경로는 기존 구성에 따라 제공한다. 접근코드 로그인을 끈 환경에서는 접근코드 인증을 제공하지 않는다.

입력 항목에는 접근 가능한 이름을 제공하고, 코드 표시·숨기기와 오류 안내를 지원한다. 모바일에서는 로그인 카드와 플랫폼 카드가 순서대로 배치된다. 키보드 포커스, 확대 글자, 내부 표 스크롤, 움직임 최소화 설정을 공통으로 지원한다.

메인에는 4개 플랫폼과 포털 업무 진입을 중심으로 표시한다. 포털 업무는 기존 역할별 첫 화면으로 바로 이동한다. 참고 디자인의 AI 입력창, 허구의 자원 수치·보안 연결 상태는 기능으로 추가하지 않았다. 기존 업무 메뉴와 API 기능은 유지하며, 외부 연계가 없는 항목은 실제 연결 상태를 표시한다.
