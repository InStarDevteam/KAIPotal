제공된 `(국방지능형) 디자인 예시.zip`의 12개 화면을 참고해 로그인과 메인 시안 4종을 개선했다. 메인뿐 아니라 기존 업무 화면에도 같은 디자인 체계를 적용하고, 군별 기본 설정과 개인 화면 설정을 연결했다. 구현 기준은 [디자인 명세](DESIGN_SPECIFICATION.md)에 정리했다.

네 시안 모두 AI·데이터·클라우드·VDI 진입, 역할에 맞는 포털 업무 진입, 상단 앱 메뉴, 개인 바로가기를 같은 방식으로 제공한다. 메인은 플랫폼 진입에 집중하며 왼쪽 메뉴를 표시하지 않는다. 업무 화면의 카드·표·입력 폼·탭·팝업·글자 크기는 공통 테마를 사용한다. 플랫폼 아이콘은 일관된 입체 SVG 계열로 개선했다.

표는 열을 좁혀 한글·날짜를 세로로 쪼개는 대신 필요한 경우 표 안에서 스크롤하도록 했다. 작은 화면의 카드 배치, 키보드 포커스, 글자 확대, 움직임 최소화 설정도 보완했다. 생산 빌드에서 생성되는 MUI 클래스 이름 때문에 로그인 스타일이 누락되던 문제와 Orbit 홈의 고정 헤더 색상 충돌을 수정했다.

## 군 관리자와 사용자 설정

| 대상 | 설정 위치 | 제공 기능 |
| --- | --- | --- |
| 군 관리자 | 군별 포털 설정 → 테마와 공통 문구 | 기본 시안, 대표·강조 색상, 로고, 공통 문구, 글자 크기 90·100·110·120% |
| 군 관리자 | 기존 메뉴·플랫폼 관리 | 메뉴 이름·노출·순서와 플랫폼 이용 권한 관리 유지 |
| 사용자 | 내 계정 → 화면 디자인과 글자 크기, 또는 마이페이지 → 화면 설정 | 군 기본값 상속 또는 개인 시안·글자 크기 저장 |
| 고객 협의 | 로그인 시안 진입 버튼·메인 하단 시안 버튼 | 같은 기능을 네 디자인으로 임시 비교 |

디자인은 **협의용 임시 선택 → 저장한 개인 디자인 → 군 기본 디자인** 순서로 적용된다. 개인 글자 크기를 지정하지 않으면 군 기본 크기를 사용한다. 설정은 계정과 소속 군을 기준으로 저장한다. 관리자나 사용자가 디자인 설정을 저장하면 임시 선택을 해제하고 저장한 설정을 적용한다. 협의용 선택 기능은 `app.designReviewEnabled`로 끌 수 있으며, 이때도 저장한 군·개인 디자인은 적용된다.

인증 전에는 공통 로그인 디자인을 사용하며, 인증 후 서버에서 확인한 소속 군의 로고·색상·기본 디자인을 적용한다. 개인 설정에서 군 기본값을 선택한 사용자는 관리자의 변경을 따른다.

기존 PostgreSQL의 군 설정과 개인 설정 JSONB를 사용했다. 테이블 신설·마이그레이션·샘플 데이터 초기화는 하지 않았다. 이전 클라이언트의 저장 요청이 새 디자인 설정을 지우지 않도록 호환성을 유지했다. 군 설정 변경 권한, 버전 충돌 검사, 감사 기록도 유지했다.

## 로그인과 기존 기능 유지

Google 로그인 버튼, OAuth 클라이언트, 별도 Firebase 인증 리스너를 제거했다. 고객 협의 환경의 접근코드 로그인과 실제 BFF 인증 토큰 발급은 유지했다. 기관 OIDC 로그인 경로도 기존 구성에 따라 유지하며, 접근코드 로그인은 해당 설정이 켜진 환경에서만 제공한다. 코드 표시·숨기기와 입력 오류 안내를 지원한다.

기존 RFP·제안서 기준의 업무 메뉴, API, 데이터, 서버에서 확인한 소속·권한을 유지했다. 참고 이미지에 있는 AI 입력창이나 허구의 자원 수치를 신규 기능으로 추가하지 않았다. 플랫폼 접속, 기관 인증·단말 보안, 파일 저장 등 미설정 외부 연계는 실제 연결 상태를 표시하며, 디자인 개선을 연동 완료로 표현하지 않는다.
